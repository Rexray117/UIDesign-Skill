# 布局、栅格与间距

---

## 一、四大基础原则

界面组织的底层原则，全部决策可回溯到这四条（源自格式塔学派）：

| 原则 | 一句话定义 | 落地规格 |
|------|-----------|----------|
| **亲密性** | 关联性越高，距离越近，越像一个视觉单元 | 纵向间距 `y = 8 + 8n`；三档规格 8 / 16 / 24px |
| **对齐** | 建立统一的视觉起点，引导视觉流向 | 文案左对齐；**表单冒号右对齐**；**数字取相同有效位数并右对齐** |
| **对比** | 建立有组织的层次，让关键信息可被快速识别 | **对比必须强烈，不可畏畏缩缩** |
| **重复** | 相同元素反复出现，降低学习成本 | 重复的对象可以是线框、颜色、要素、格式或空间关系 |

**关于「对比」的一条补充纪律**：
突出重点的方法**不限于强化重点项，也可以是弱化其他项**。
且在需要用户慎重决策的场景（如审批「通过/驳回」），系统应保持中立——两个操作都用次按钮，**不能替用户或诱导用户做判断**。

## 二、间距体系

### 2.1 基数

统一 **4px 基数**（8px 亦常见）。取 4 或 8 取决于所需密度。

```css
--space-1:  4px;    --space-2:  8px;
--space-3:  12px;   --space-4:  16px;
--space-6:  24px;   --space-8:  32px;
--space-12: 48px;   --space-16: 64px;
```

**严禁魔法数字**（`11px`、`13px`）。若尺度里没有你需要的档位，**说明设计需要重审，而不是打一个一像素补丁**。

### 2.2 三档纵向间距（亲密性的落地）

| 档位 | 值 | 用途 |
|:----:|:--:|------|
| 小 | 8px | 同组内元素（标签与值、图标与文字） |
| 中 | 16px | 相关字段之间 |
| 大 | 24px | 不同信息组之间 |

不适用时按基数倍数扩展：`y = 8 + 8n`（n ≥ 0）。

### 2.3 间距层级（必须拉开）

| 层级 | 间距 | 纪律 |
|------|:----:|------|
| 组件内 | 4–12px | — |
| 组件间 | 12–24px | — |
| 区块内 | 24–32px | — |
| 区块间 | 32–48px | **≥ 组件间 ×2** |
| 章节间 | 48–96px | **≥ 区块间 ×2** |

> **最常见的 AI 味之一**：所有间距差不多大，层级消失。
> **判据**：区块间距至少是内部间距的 **3 倍**。

### 2.4 按密度缩放（三旋钮之 --density）

| `--density` | 间距尺度 | 适用 |
|:-----------:|----------|------|
| 1–3 | 24 / 48 / 96px | 营销页 |
| 4–7 | 16 / 32 / 64px | 用户界面、管理界面 |
| 8–10 | 8 / 16 / 32px | 监控界面、大屏 |

**换密度不是改一堆数值，而是换整张尺度表。** 这正是 token 化的价值。

## 三、栅格

### 3.1 画板与断点

| 项 | 值 |
|----|----|
| 桌面画板基准 | **1440px** |
| 主流分辨率 | 1920 / 1440 / 1366（个别 1280） |
| 断点 | **375 / 768 / 1024 / 1440**（系统化，不用随机值） |

### 3.2 栅格体系

| 项 | 建议 |
|----|------|
| 列数 | **12 列**（通用）或 **24 列**（高密度管理界面） |
| Gutter | **固定值**（不随宽度变化） |
| 外边距 | 随断点增大：16 / 24 / 32 / 48px |
| 内容最大宽 | 1280–1440px 后居中 |

**「Gutter 固定、Column 伸缩」是栅格的核心机制**：浏览器宽度变化时只有列宽变，槽宽不变。

### 3.3 适配的两种基本方案

| 方案 | 做法 | 适用 |
|------|------|------|
| **左右布局** | 左侧导航固定，右侧工作区动态缩放 | 管理界面、监控界面 |
| **上下布局** | 两侧留白设最小值，达到限定值后再缩放主内容区 | 营销页、内容站 |

## 四、表面层级（三层模型）

| 层 | 用途 | 区分手段 |
|----|------|----------|
| **页面背景** | 环绕并承载一切 | 最深的底 |
| **容器表面** | 卡片、面板、表格、表单 | 白面 / 最亮 |
| **抬升表面** | 模态、下拉、气泡 | **与前层同色，靠阴影区分** |

> **关键**：模态与卡片**可以是同一个颜色**。层级由阴影而非颜色表达。
> 这样暗色模式只需翻转「表面阶梯」，不必重设整套色值。

**纪律**：
- 禁止硬编码表面色（`#FFF` / `#FAFAFA`）
- 层级不超过 3 层（再多就是层级失控）
- 暗色下阴影失效 → 改用表面明度差 + 边框

## 五、非对称与节奏（治 D1 对称惯性）

### 5.1 三种安全的非对称做法

| 做法 | 说明 | 例子 |
|------|------|------|
| **跨列** | 主元素跨 2 列，次元素各占 1 列 | 主卡 `span 2`，两个次卡各 `span 1` |
| **偏移** | 整体偏左或偏右，留一块负空间 | 标题占左 7 栏，右侧 5 栏留空 |
| **尺寸对比** | 同一行元素宽高不等 | 7:3、8:5，而非 1:1 |

**非对称不是「摆歪」**，是用不平衡制造视觉权重。**阅读起点仍须唯一**。

### 5.2 节奏（避免留白均匀）

| 手段 | 说明 |
|------|------|
| 间距层级差 | 无层级 → 有层级（见 §2.3） |
| 密度交替 | 密集区与稀疏区交替出现 |
| 尺寸跳跃 | 大标题与极小标签相邻（4× 以上反差） |
| 分隔手段变化 | 有时用线、有时用底色、有时仅用间距 |

## 六、信息层级（内容决定结构）

### 6.1 先内容后骨架

```
1. 列出这一屏必须承载的全部内容项（不要先想布局）
2. 标出「谁最先被看」（唯一答案）
3. 标记内容之间的真实关系：并列 / 主从 / 时序 / 因果
4. 关系决定结构：
   并列 → 网格          主从 → 主卡 + 次级
   时序 → 纵向流        因果 → 分组 + 分隔
5. 现在才画骨架
```

**跳过第 1–3 步直接画骨架，就是结构同构（D5）的成因。**

### 6.2 模块数量

| 场景 | 单屏并列模块 |
|------|:-----------:|
| 用户界面 | 3–6 |
| 管理界面 | 4–9 |
| 监控界面 | 6–12（密度是特征） |
| 大屏 | **3–5**（远距可读） |

**必须有一个视觉上明显的主模块。**

### 6.3 区隔手段（按信息关系选）

| 手段 | 适用 |
|------|------|
| 间距 | 同组内、关系最近 |
| 不通栏分割线 | 相关内容之间 |
| 通栏分割线 | 不同部分之间 |
| 卡片 | 一个主题 |
| 页签 / 分步 | 最顶层的组织方式 |

## 七、固定元素与安全区

| 项 | 纪律 |
|----|------|
| 固定导航 / 底栏 | 必须为内容预留等高的内边距，**不得遮挡内容** |
| 移动端安全区 | 使用 `env(safe-area-inset-*)`；避让刘海、状态栏、手势条 |
| 视口单位 | 移动端用 `dvh` 而非 `vh` |
| z-index | 建立明确尺度（如 `0 / 10 / 20 / 40 / 100 / 1000`），**禁止随意取 9999** |
| 滚动 | 避免嵌套滚动区干扰主滚动 |
| 横向滚动 | 任何断点都不得出现 |

## 八、布局自检

**间距**
- [ ] 全部取值在尺度内，无魔法数字
- [ ] 区块间距 ≥ 内部间距 ×3
- [ ] 纵向间距按 `8 + 8n` 规律
- [ ] 密度旋钮已设定且全局一致

**栅格**
- [ ] Gutter 固定、Column 伸缩
- [ ] 断点系统化（375/768/1024/1440）
- [ ] 内容最大宽已限制
- [ ] 外边距随断点变化

**层级**
- [ ] 表面 ≤3 层
- [ ] 浮层靠阴影/明度区分，非靠颜色
- [ ] z-index 走尺度

**结构与节奏**
- [ ] 非对称结构 ≥3 处（跨列/偏移/尺寸对比）
- [ ] 阅读起点唯一
- [ ] 单屏模块数在场景范围内
- [ ] 结构由内容决定（走完「先内容后骨架」五步）
- [ ] 无连续同构区块

**响应式**
- [ ] 375 / 768 / 1024 / 1440 均验证
- [ ] 无横向滚动
- [ ] 固定元素未遮挡内容
- [ ] 安全区已适配
- [ ] 横屏可用
