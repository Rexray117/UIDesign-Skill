# 排版与色彩体系

---

## 第一部分 · 排版

### 一、基准字号（按场景定，不是一刀切）

| 场景 | 正文基准 | 理由 |
|------|:--------:|------|
| 用户界面 / C 端移动端 | **16px** | 可读性优先；低于 16px 会触发 iOS 自动缩放 |
| 营销落地页 | **16px** | 同上 |
| 管理界面（桌面） | **14px** | 桌面高密度：1440px 要容纳侧栏 + 表头 + 8 列数据 + 详情面板；14px 下正文可达约 75 字符扫视甜点区 |
| 企业监控界面 | **12–13px** | 一屏看完是硬需求；但**大屏场景反向提高到 ≥18px** |
| 数据可视化大屏 | **≥18px**（近距）/ **≥32px**（6m+） | 按观看距离反推 |

> ⚠️ **低基准只适用于桌面高密度场景。** 若同一产品需在移动端可用，移动端必须回到 16px。

### 二、字号尺度

至少 **5 档**，且**最大 / 最小 ≥ 3.5×**（营销页 ≥4×）。

| 角色 | 用户界面 | 管理界面 | 大屏 |
|------|:--------:|:--------:|:----:|
| 关键数字 / Display | 40–64px | 32–48px | 72–200px |
| 页面主标题 | 28–38px | 20–24px | 40–64px |
| 区块标题 | 18–20px | 16–18px | 24–32px |
| 正文 | 16px | 14px | 18–24px |
| 表格正文 | 14px | 12–13px | 16–18px |
| 标签 / 说明 | 13px | 12px | 18px |
| 最小 | 12px | 11px | 18px |

### 三、行高

| 内容类型 | 行高 |
|----------|------|
| 大标题 | 1.1–1.25 |
| 小标题 | 1.3–1.4 |
| 正文 | **1.5–1.75** |
| 数据行 | 1.3–1.4 |
| 表格 | 1.3–1.4 |

### 四、行宽

| 场景 | 字符数 |
|------|:------:|
| 移动端 | 35–60 |
| 桌面 | 60–75 |
| 大屏 | 更短（约 30–45），因观看距离 |

### 五、字重（≤3 档）

| 字重 | 用途 |
|:----:|------|
| 400 | 正文、控件、菜单项、标签 |
| 500 | 中重：标签、按钮文字、表格强调 |
| 600 | 标题、表头、关键数字 |

**纪律**：
- **禁用 100–300**（细体）于界面 chrome —— 与「平静、确定」的调性冲突，且低分辨率下糊
- **禁用 700+**（粗体）于界面 chrome —— 过重会制造噪声
- 斜体仅用于长文档正文，不用于界面
- **选中/激活态的强调来自颜色与描边，不来自字重**

> 企业级产品可**只用 400 + 600 两档**（Ant Design 口径），但必须**用字距与色彩补偿层次**。

### 六、字距

| 情形 | 处理 |
|------|------|
| 大字号标题（≥28px） | 收紧（`-0.02em`）；**中文标题一般不收紧** |
| 小字号全大写 | 放开（`+0.05em`） |
| 数据标签 | 放开（`+0.04em`） |
| 正文 | 保持默认，**不得收紧** |

### 七、数字排版

| 规则 | 说明 |
|------|------|
| **等宽数字** | 数据列、价格、计时必须 `font-variant-numeric: tabular-nums` |
| 右对齐 | 数值列一律右对齐 |
| 相同有效位数 | 便于快速比对大小 |
| 单位处理 | 单位字号小于数值（或用较小字重） |
| 禁止 | 比例数字用于表格（会导致列宽跳动） |

### 八、字体选型

| 策略 | 何时用 |
|------|--------|
| **系统字体栈** | 默认选择。性能最好 + 平台原生感 |
| 单一开源字体 | 需要统一跨平台观感时（如 Inter、Plus Jakarta Sans） |
| 双字体配对 | 需要明确性格时（标题 + 正文分工） |

**系统字体栈推荐**：
```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
             "Helvetica Neue", Arial, "Noto Sans", sans-serif;
```

**等宽栈**：
```css
font-family: "SFMono-Regular", Consolas, "Liberation Mono", Menlo, monospace;
```

**配对原则**：
- 标题与正文的**性格必须一致**（都现代 / 都古典），不要混搭气质冲突的
- **单字族方案（如 Inter + Inter）是完全合法的正统选项** —— 用字重与字号做层次即可
- 中文场景注意：多数西文配对的中文回退需要显式声明，否则会出现字重断层

> 74 组已验证的配对见 `data/typography.csv`。

## 第二部分 · 色彩

### 一、色彩预算（硬约束）

| 项 | 上限 |
|----|:----:|
| 唯一色相（不含中性灰） | **≤3** |
| 强调色 | **1** |
| 中性灰档位 | **4–8** |
| 同屏功能色（成功/警告/错误/信息） | 按需，但**只用于状态** |
| 分类色（标签/图表） | ≤8，且**不得用于主操作** |

**超预算就是 D2 色彩惰性。** 收敛方法见 `../anti-ai/fixes.md` §D2。

### 二、主色选择

| 原则 | 说明 |
|------|------|
| 从产品/行业出发 | 不是从「好看」出发 |
| 品牌色存在时优先用品牌色 | 不要为了「现代感」换成靛蓝或紫色 |
| 亮度足够承载白字 | 否则需加深或改深色文字 |
| **有立场** | 换到竞品上会显得不对 |

> 192 类产品的推荐色板见 `data/colors.csv`（含完整 `On-*` 配对色）。
> ⚠️ 照搬色板时必须**连同 `On-*` 一起搬**——部分配色的辅色是**亮色填充配深色文字**，不是常规的「深填充配白字」。

### 三、中性色

**必须 ≥4 档**，建议按下表：

| 档位 | 用途 | 对比要求 |
|------|------|----------|
| 主文字 | 正文、标题 | ≥4.5:1（≥7:1 为增强目标） |
| 次文字 | 辅助说明、标签 | ≥4.5:1 |
| 三级文字 | 说明、占位 | ≥4.5:1（若为正文职责） |
| 禁用 / 占位 | 禁用态、placeholder | ≥3:1（不得作为正文） |

**实现建议**：用 `rgba(0,0,0,α)` 而非不透明灰——浮在有色表面上时能自然融合，不破坏色相。

### 四、功能色（状态）

| 状态 | 常规色 | 配对 |
|------|--------|------|
| 成功 | `#16A34A` | 白字 / 深绿字（浅底时） |
| 警告 | `#D97706` | 白字 / 深棕字 |
| 错误 | `#DC2626` | 白字 |
| 信息 | `#2563EB` | 白字 |

**纪律**：
- 功能色**只用于状态**，不用于装饰
- **状态色必须配图标或形状** —— 不得仅靠颜色（色盲安全）
- 状态色的三档底色（浅/中/深）需成组定义，不要临时取色

### 五、对比度红线

| 元素 | 最低 | 增强目标 |
|------|:----:|:--------:|
| 正文 | 4.5:1 | 7:1 |
| 大字号（18px+ 或 14px+ 粗体） | 3:1 | 4.5:1 |
| UI 组件边界 | 3:1 | — |
| 焦点指示器 | 3:1 | — |
| 图标（有语义） | 3:1 | — |
| 图表数据线/柱 vs 背景 | 3:1 | — |
| 图表数据标签 | 4.5:1 | — |

### 六、暗色模式

| 纪律 | 说明 |
|------|------|
| **不是反转颜色** | 去饱和、提亮文字、重设边框 |
| 底色不用纯黑满屏 | `#0B0E14`–`#181818` 优于 `#000000`（减少溢光与拖影）；纯黑仅用于 OLED 优化场景 |
| 文字不用纯白 | `#E0E0E0`–`#FFFFFF`；纯白在黑底上会产生光晕 |
| 边框必须重设 | 亮色边框值在暗色下会消失 |
| 对比独立测试 | **绝不假设亮色值可沿用** |
| 状态色去饱和 | 亮色主题的高饱和色在暗色下会「刺眼」 |
| 阴影失效 | 暗色下层级主要靠**表面明度差**与边框，不靠阴影 |
| 图像处理 | 亮色图片需降亮度，否则刺眼 |

### 七、渐变使用纪律

**渐变只允许三种合法用途**：

| 合法用途 | 例子 |
|----------|------|
| 表现材质 | 玻璃、液体、金属 |
| 表现深度 | 空间层级、光照 |
| 表现进度/热力 | 数据映射、进度条 |

**其他用途一律删除。** 特别是：
- ❌ 装饰性背景渐变（AI 味最高）
- ❌ 紫→粉 / 蓝→紫 色对（AI 默认套餐）
- ❌ 渐变文字（可读性差）

若品牌需要背景渐变，**色对必须来自品牌**，且文字必须压遮罩保证 4.5:1。

### 八、色彩自检

- [ ] 色相 ≤3（不含中性灰）
- [ ] 强调色恰好 1 个
- [ ] 中性灰 ≥4 档且层次分明
- [ ] 组件内无裸 hex（全部走 token）
- [ ] 渐变都有合法理由（材质/深度/进度）
- [ ] 无紫粉色对
- [ ] 文字对比 ≥4.5:1（大字与 UI ≥3:1）
- [ ] 暗色独立测过对比
- [ ] 状态色都配了图标或形状
- [ ] 分类色未用于主操作
