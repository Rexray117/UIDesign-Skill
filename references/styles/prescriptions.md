# 风格处方（24 种）

每种风格统一给出六项：**Token 处方 · 差异化抓手 · AI 味陷阱 · 适用 · 禁用 · 落地检查**。

> **「AI 味陷阱」是必读项。** 它记录的是「用这个风格时，AI 最容易在哪里做成烂大街的样子」——
> 知道了陷阱，才能在该风格里做出辨识度。

## A 组 · 中性骨干

### 01 Swiss Minimalism

| 项 | 内容 |
|----|------|
| 特征 | 网格、留白、无衬线、零装饰、单一强调色、层级只靠字号与间距 |
| 色彩 | 1 中性底 + 4 档灰（主/次/三级/禁用）+ **1 个强调色**。禁止第二个强调色 |
| 排版 | 字重 400/500/600；字号档 ≥5 且最大/最小 ≥3.5×；**标题收紧字距** |
| 形状 | 圆角 0–4px（锐利是其语言）；无阴影，层级靠 1px 边框或底色 |
| 间距 | 遵循 4/8 基数；**区块间距 ≥ 内部间距 ×3**；留白是被分配的资源 |
| 动效 | 仅 150–200ms 状态变化；无入场动画 |
| **差异化抓手** | **一个极端的字号跳跃**——例如标题 12px 全大写小标签，紧邻 64px 主数字 |
| **AI 味陷阱** | ① 做成「性冷淡模板」：全是灰，没有立场 → **必须有 1 个强调色且敢用** ② 留白均匀无节奏 → **用间距的层级差制造呼吸** ③ 所有元素一样重 → **必须有唯一焦点** |
| 适用 | 管理界面、用户界面、文档站、企业官网 |
| 禁用 | 需要情绪张力的营销页、数据大屏 |
| 落地检查 | 强调色是否只有 1 个？最大/最小字号比 ≥3.5×？是否有唯一视觉焦点？ |

### 02 Flat Design

| 项 | 内容 |
|----|------|
| 特征 | 无阴影无质感、纯色块、清晰边界、图标化 |
| 色彩 | 色块承担结构；建议 1 主 + 2 辅 + 中性；**色块之间靠明度差而非边框** |
| 排版 | 字重 400/500/600；行高 1.5–1.7 |
| 形状 | 圆角统一（2–8px）；**零阴影** |
| 间距 | 4/8 基数，组件内 8–16，区块间 32–64 |
| 动效 | 仅颜色/透明度过渡 150ms |
| **差异化抓手** | **色块的非常规比例**——例如一条 4px 的高饱和色带贯穿页面，或侧边色块占 1/5 宽 |
| **AI 味陷阱** | ① 沦为「默认主题」：一堆等宽圆角卡片 → **必须有不规则的色块比例** ② 靠数量堆砌（8 种色块）→ **限 3 色以内** ③ 无层级（全部同一明度）→ **至少 3 档明度** |
| 适用 | C 端移动端、管理界面、用户界面 |
| 禁用 | 需要深度隐喻的场景（3D 预览、空间 UI） |
| 落地检查 | 色数 ≤3？有色块比例差异？零阴影？ |

### 03 Bento Box Grid

| 项 | 内容 |
|----|------|
| 特征 | 大小不等的卡片在网格中拼合，靠**尺寸对比**建层次 |
| 色彩 | 卡片可用不同底色（同色相不同明度）区分；强调色只给 1 张卡 |
| 排版 | 大卡字号跳档（如 32/20/14）；小卡统一 14 |
| 形状 | 圆角统一一档（12–20px）；卡片间 gap 明确（12–20px） |
| 间距 | 卡片内 20–24px；卡片间等于 gap |
| 动效 | 卡片 hover 微抬升（150ms）**仅限可点击卡** |
| **差异化抓手** | **一张跨 2×2 的主卡 + 其余 1×1 小卡**——比例失衡本身就是设计 |
| **AI 味陷阱** | ① **最容易被套用的「现代感」**：等大 3×2 网格 → **必须跨列跨行** ② 每张卡都有阴影 + 圆角 + hover → **只留一个** ③ 卡片数量失控（12 张）→ **5–8 张** |
| 适用 | 营销落地页、C 端移动端、用户界面 |
| 禁用 | 线性流程场景、密集数据 |
| 落地检查 | 是否有 ≥1 张跨列/跨行卡？卡片数 5–8？阴影只用于可点击卡？ |

### 04 Editorial Grid

| 项 | 内容 |
|----|------|
| 特征 | 杂志式多栏、大标题、图文咬合、参差栏宽 |
| 色彩 | 近乎单色（黑白 + 1 强调）；靠字号与留白做张力 |
| 排版 | **衬线/无衬线对比**或用同一字族的极端字重对比；标题可跨栏 |
| 形状 | 零圆角（页面的语言是「印刷」） |
| 间距 | 栏间 gap 大（32–48px）；正文行宽 60–75 字符 |
| 动效 | 几乎无；仅图片淡入 |
| **差异化抓手** | **一个跨越栏线的大标题**，与下方小字形成 5× 以上反差 |
| **AI 味陷阱** | ① 排版工整无咬合 → **必须让标题/图片突破栏线** ② 字号对比不足 → **标题/正文 ≥4×** |
| 适用 | 营销落地页、内容型产品、品牌官网 |
| 禁用 | 管理界面、密集数据 |
| 落地检查 | 是否有元素跨越栏线？行宽 60–75 字符？ |

## B 组 · 企业数据

### 05 Data-Dense Dashboard

| 项 | 内容 |
|----|------|
| 特征 | 高密度、等宽数字、紧凑表格、极小留白、信息优先 |
| 色彩 | 中性底 + 语义色（成功/警告/错误）。**UI 保持中性，色彩留给数据** |
| 排版 | 正文 12–13px；**数字必须 `tabular-nums` + 右对齐 + 相同有效位数**；标签 11–12px 全大写或字距放开 |
| 形状 | 圆角 2–4px；1px 边框做分隔；**阴影仅用于浮层** |
| 间距 | 4 基数，行高紧凑（行内 4–8，区块间 16–24）。**密度 ≥8** |
| 动效 | **仅数据更新时的数值变化**；禁止装饰动画 |
| **差异化抓手** | **告警数字用超大等宽字号（36–56px）**，与周围 12px 形成 4× 反差——一眼定位异常 |
| **AI 味陷阱** | ① 「太密了改成卡片留白」→ **这是误杀**，密度是特征 ② 无层次导致糊 → **必须放大对比层次**（主/次/三级灰度分明） ③ 用彩色 UI 抢数据的色 → **UI 中性** |
| 适用 | 企业监控界面、管理界面、数据大屏 |
| 禁用 | 营销页、C 端消费级产品 |
| 落地检查 | 数字等宽右对齐？留白是否被误删？UI 是否保持中性？对比层次是否够？ |

### 06 Dark Mode (OLED)

| 项 | 内容 |
|----|------|
| 特征 | 深黑/深灰底、去饱和、克制光、高对比 |
| 色彩 | 底 `#000000` 或 `#121212`；文字不用纯白（用 `#E0E0E0`–`#FFFFFF`）；点缀色**去饱和后**使用；对比 **≥7:1** |
| 排版 | 同基础规范；暗色下**字重可降一档**（亮字看起来更粗） |
| 形状 | 圆角适度；**边框在暗色下必须可见**（不可直接沿用亮色边框值） |
| 间距 | 同基础规范 |
| 动效 | 可略强（暗色容忍度高）；仍受 `prefers-reduced-motion` 约束 |
| **差异化抓手** | **一处极克制的单色辉光**，只用于「当前活跃」的元素 |
| **AI 味陷阱** | ① **简单反转颜色** → 必须独立设计暗色，去饱和、重设边框、重测对比 ② 到处发光 → **辉光只给 1 处** ③ 「暗色换皮」白天也暗 → 提供亮色版或明确理由 |
| 适用 | 企业监控界面、数据大屏、夜间使用的工具 |
| 禁用 | 印刷优先内容、强光户外、色彩精度关键场景 |
| 落地检查 | 对比度独立测过？边框在暗色下可见？辉光 ≤1 处？ |

### 07 Terminal CLI

| 项 | 内容 |
|----|------|
| 特征 | 等宽、字符网格、无圆角、高对比、无装饰 |
| 色彩 | 底黑/深灰 + 前景浅灰 + **1–2 个终端色**（绿/琥珀）；色彩语义固定 |
| 排版 | 全局等宽；字号 12–14px；行高 1.3–1.5；**字符对齐是布局基础** |
| 形状 | 圆角 0；无阴影；分隔用字符或 1px 线 |
| 间距 | 以字符为单位（1ch / 1lh） |
| 动效 | 仅光标闪烁与内容追加 |
| **差异化抓手** | **一处非终端语言的元素**——例如状态用色块而非文字，形成陌生化对比 |
| **AI 味陷阱** | ① 全等宽导致无层次 → **靠缩进、反色块、强度（亮/暗）建立层级** ② 过度模仿老式 CRT 扫描线 → 除非品牌如此，否则删 |
| 适用 | 企业监控界面（日志/终端区）、开发者工具 |
| 禁用 | 面向非技术用户、营销页 |
| 落地检查 | 层级是否靠缩进/反色建立？字符是否严格对齐？ |

### 08 HUD / Sci-Fi FUI

| 项 | 内容 |
|----|------|
| 特征 | 环形仪表、刻度、准星、框架线、发光边界、角标 |
| 色彩 | 暗底 + 1 高饱和功能色（青/绿/橙）；发光限于「边界与活跃态」 |
| 排版 | 数字超大且等宽；标签极小 + 放开字距 |
| 形状 | 圆/环/斜切角；**斜切角是其签名** |
| 间距 | 紧凑；框架线承担分组 |
| 动效 | 中高强度（扫描、脉冲），**但告警优先于动效** |
| **差异化抓手** | **一个自定义的刻度/环状仪表**，而非进度条 |
| **AI 味陷阱** | ① 过度发光（到处 glow）→ **发光只给边界与活跃态** ② 装饰性扫描线/雷达波盖住数据 → **装饰不得遮挡或干扰读数** ③ 用于管理系统 → 功能性错误 |
| 适用 | 企业监控界面、数据大屏 |
| 禁用 | 管理界面、面向普通用户的场景 |
| 落地检查 | 发光 ≤2 处且都有语义？装饰未遮挡数据？告警是否最醒目？ |

## C 组 · 质感材质

### 09 Glassmorphism

| 项 | 内容 |
|----|------|
| 特征 | 毛玻璃、半透明、模糊背景、细边、Z 轴深度 |
| 色彩 | 半透明白 10–30%；**必须有鲜艳或影像底**才成立；文字对比须实测 |
| 排版 | 同基础规范；**玻璃面上文字需加深或加背景**保证 4.5:1 |
| 形状 | 圆角 12–20px；1px 细边（`rgba(255,255,255,0.2)`） |
| 间距 | 同基础规范 |
| 动效 | 180–240ms；可加极轻微视差表现深度 |
| **差异化抓手** | **玻璃只用在「必须浮起来」的层级**（导航、模态、悬浮面板），其余实心 |
| **AI 味陷阱** | ① **最泛用的「现代 SaaS」默认**：所有卡片都毛玻璃 + 紫粉渐变底 → **必须换掉渐变底，且玻璃限层级** ② 对比度不足 → 实测文字 4.5:1 ③ 性能问题（多层 backdrop-filter）→ 同屏 ≤3 层 |
| 适用 | 用户界面、营销落地页、浮层与导航 |
| 禁用 | 密集数据、低对比底、性能受限 |
| 落地检查 | 底层是否足够鲜艳？文字对比实测过？同屏玻璃层 ≤3？ |

### 10 Liquid Glass

| 项 | 内容 |
|----|------|
| 特征 | 折射、高光、弹性形变、有机曲率、液体材质 |
| 色彩 | 玻璃质感 + 高光渐变（**此处渐变合法**：表达材质）；强调色 1 个 |
| 排版 | 字重可到 600；间距宽松（表达「高级」） |
| 形状 | 大曲率、连续圆角（squircle）；形状本身是主体 |
| 间距 | 宽松（24–48px） |
| 动效 | 中高（弹性、形变跟随），必须可中断 |
| **差异化抓手** | **一处真实的折射/高光**（而非平面渐变）——例如按钮按下时的形变 |
| **AI 味陷阱** | ① 用平面线性渐变冒充液体 → **必须有曲率与高光的空间关系** ② 和高饱和色撞色导致浑浊 → 底层用低饱和或中性 + 局部彩色 |
| 适用 | 用户界面、营销落地页、C 端移动端、奢侈品电商 |
| 禁用 | 密集数据、管理界面 |
| 落地检查 | 是否有真实的空间光感？动效可中断？ |

### 11 Soft UI Evolution

| 项 | 内容 |
|----|------|
| 特征 | 柔和阴影、微妙深度、低饱和、calming、有机形状 |
| 色彩 | 低饱和柔色（柔粉/鼠尾草绿/米白）+ 1 个金/暖色点缀 |
| 排版 | 字重 400/500；字号温和（避免极端对比，此风格的调性是「缓」） |
| 形状 | 圆角 12–24px；**单向柔影（非 Neumorphism 的双向）** |
| 间距 | 宽松（24–64px） |
| 动效 | 缓慢（300–400ms）、ease-out |
| **差异化抓手** | **一个有机形状的弯曲分割线或斜切区块**，打破矩形的单调 |
| **AI 味陷阱** | ① 与 Neumorphism 混淆 → **Soft UI 是单向柔影 + 低饱和；Neu 是单色系 + 双向柔影** ② 太软导致无重点 → **必须保留 1 处高对比焦点** |
| 适用 | 用户界面、健康/美容/生活方式产品 |
| 禁用 | 数据密集、企业监控 |
| 落地检查 | 阴影是否单向？是否保留了一个高对比焦点？ |

### 12 Neumorphism

| 项 | 内容 |
|----|------|
| 特征 | 单色系 + 双向柔影，同一材质被挤压（浮雕/凹雕） |
| 色彩 | **单色系**（同色相 3–4 档明度差）；强调色极少用 |
| 排版 | 字重 400/500；对比度通过明度而非色彩 |
| 形状 | 圆角 12–16px；**双向阴影**：`-5px -5px 15px` 亮 + `5px 5px 15px` 暗 |
| 间距 | 中等（16–32px） |
| 动效 | 按下时阴影内翻（150ms） |
| **差异化抓手** | **用「凹陷」表达选中态**（而非加边框或变色），保持材质一致性 |
| **AI 味陷阱** | ① **无障碍风险高**：对比度天然不足 → 正文/控件对比必须实测 ≥4.5:1 / 3:1 ② 用于复杂应用 → 状态区分度不够 ③ 用于告警 → 柔影削弱打断力 |
| 适用 | 健康、冥想、健身等**低频交互**的移动应用 |
| 禁用 | 企业监控、管理界面、数据密集、无障碍关键 |
| 落地检查 | 对比度实测达标？交互频率是否足够低？ |

## D 组 · 温度亲和

### 13 Claymorphism

| 项 | 内容 |
|----|------|
| 特征 | 粉彩、粗边 3–4px、内外双阴影、玩具实体感 |
| 色彩 | 粉彩（桃/婴蓝/薄荷/丁香）+ 低饱和底 |
| 排版 | 字重 500/600（圆润字体优先）；字号偏大 |
| 形状 | 圆角 16–24px；**边框 3–4px**（区别于 Neumorphism 的关键） |
| 间距 | 宽松（24–48px） |
| 动效 | 弹性 `cubic-bezier(0.34, 1.56)`，200–300ms |
| **差异化抓手** | **粗边框 + 内阴影组合出的「厚度感」**，而非单纯圆角 |
| **AI 味陷阱** | ① 只加圆角不加粗边 → 就变成普通圆角卡片 ② 用于正式/金融/医疗 → 调性冲突 |
| 适用 | 教育、儿童、C 端移动端、创意工具、引导页 |
| 禁用 | 正式企业、金融、医疗、数据关键 |
| 落地检查 | 边框是否 3–4px？是否有内阴影？ |

### 14 Organic Biophilic

| 项 | 内容 |
|----|------|
| 特征 | 有机曲线、自然色、生物形态、非矩形 |
| 色彩 | 自然色（土/苔/叶/沙）+ 1 个柔和点缀；低饱和 |
| 排版 | 衬线或无衬线人体工学字体；行高宽松 1.7 |
| 形状 | **非规则曲线/不规则圆角**（`border-radius` 各角不同）；避免直角 |
| 间距 | 宽松（32–80px），模拟自然呼吸 |
| 动效 | 缓慢、有机（不匀速），250–400ms |
| **差异化抓手** | **一处不规则形状的分区**（如斜向曲线分割），替代直线分隔 |
| **AI 味陷阱** | ① 只是「绿色 + 圆角」→ **必须有非规则的曲线形态** ② 颜色过艳 → 自然色是低饱和的 |
| 适用 | 可持续/健康/生活方式品牌、营销落地页 |
| 禁用 | 企业监控、数据密集 |
| 落地检查 | 是否有非矩形形态？饱和度是否够低？ |

### 15 Skeuomorphism

| 项 | 内容 |
|----|------|
| 特征 | 拟物、真实材质、物理隐喻、纹理 |
| 色彩 | 材质本色（皮革/金属/纸/木）；光照关系写实 |
| 排版 | 与材质协调的字体（铭牌用衬线、标签用无衬线） |
| 形状 | 跟随物理对象（按钮有厚度、旋钮有刻度） |
| 间距 | 跟随物理布局逻辑 |
| 动效 | 物理性（按压凹陷、旋钮转动） |
| **差异化抓手** | **一个承担真实隐喻的控件**（如可拖动的旋钮），而非通用的滑块 |
| **AI 味陷阱** | ① 为拟物而拟物（贴个金属纹理当背景）→ **隐喻必须成立** ② 与扁平混用 → 材质语义打架 |
| 适用 | 特定工具类产品（音频/乐器/专业设备）、怀旧向产品 |
| 禁用 | 密集数据、管理界面、无障碍关键 |
| 落地检查 | 隐喻是否成立？是否与扁平元素混用？ |

### 16 Vintage Analog

| 项 | 内容 |
|----|------|
| 特征 | 胶片颗粒、暖调、纸张质感、复古字体、套色偏移 |
| 色彩 | 暖调低饱和（奶油/砖红/墨绿/赭石）；可加轻微套色错位 |
| 排版 | 古董衬线 / 手写体 / 厂牌式无衬线；字距放开 |
| 形状 | 多为直角或极小小圆角；边框像印刷边线 |
| 间距 | 中等；模拟印刷栏宽 |
| 动效 | 极少；可有纸张翻动感 |
| **差异化抓手** | **一处真实的印刷痕迹**（颗粒、套色偏移、油墨扩散） |
| **AI 味陷阱** | ① 只换成米色就以为复古 → **必须有颗粒/偏移等材质细节** ② 用于需要精确读数的界面 |
| 适用 | 品牌官网、文化活动、餐饮/手工品牌 |
| 禁用 | 企业监控、管理界面、数据密集 |
| 落地检查 | 是否有材质细节（非仅换色）？ |

## E 组 · 表现运动

### 17 Brutalism & Neubrutalism

| 项 | 内容 |
|----|------|
| 特征 | 硬边框、纯色、无圆角、粗黑字体、生硬位移阴影 |
| 色彩 | 纯色高饱和（红/蓝/黄）+ 黑白；**色数严格受限** |
| 排版 | 超粗字重（700–900）；字号对比极端；可混用等宽 |
| 形状 | 圆角 0；**硬边 2–4px**；硬阴影（无模糊，偏移 4–8px） |
| 间距 | 大块面 + 大间距（32–64px） |
| 动效 | 生硬、即时（0–100ms），或故意无过渡 |
| **差异化抓手** | **无模糊的硬阴影 + 2–4px 黑边**——这套组合本身就是签名 |
| **AI 味陷阱** | ① 只做成「黑边圆角卡」→ 圆角必须为 0 ② 颜色乱用 → **限 3 色** ③ 用于企业/合规场景 → 调性冲突 |
| 适用 | 营销落地页、创意机构、开发者工具、活动页 |
| 禁用 | 保守行业、政府医疗、无障碍关键 |
| 落地检查 | 圆角是否为 0？阴影是否无模糊？色数 ≤3？ |

### 18 Kinetic Typography

| 项 | 内容 |
|----|------|
| 特征 | 字体本身是主体，字随滚动/交互变形、位移、分割 |
| 色彩 | 近单色（字体是主角）；1 强调色 |
| 排版 | 极端字号（可达视口宽度）；可变量字体优先 |
| 形状 | 形状由字体构成，不引入额外装饰 |
| 间距 | 由字体尺寸决定 |
| 动效 | 高强度；**必须可中断 + 支持 reduced-motion 降级为静态排版** |
| **差异化抓手** | **一处字体形变/分割**，其余文字保持静止 |
| **AI 味陷阱** | ① 全屏都在动 → 只有 1 处动 ② 不降级导致无障碍失败 → 必须有静态版 |
| 适用 | 营销落地页、品牌宣言页、活动页 |
| 禁用 | 管理界面、需要快速读取信息的场景 |
| 落地检查 | 是否只有 1 处动效？有无 reduced-motion 降级？ |

### 19 Motion-Driven

| 项 | 内容 |
|----|------|
| 特征 | 动效承担信息结构，滚动即叙事，元素间的时空关系被显式表达 |
| 色彩 | 中性为主（动效是主角）；1 强调色 |
| 排版 | 清晰层级（动效在揭示层级，排版需先明确） |
| 形状 | 中性 |
| 间距 | 需为动效预留空间（章节间距大，80–160px） |
| 动效 | 高强度：pin、视差多层、共享元素转场；**每屏 ≤2 个动画元素** |
| **差异化抓手** | **一处「滚动即揭示结构」的编排**（如左侧文字固定、右侧图形随之变换） |
| **AI 味陷阱** | ① 炫技无意义 → **每个动效必须表达因果关系** ② 出场比入场慢 → 出场应为入场的 **60–70%** ③ 无 `prefers-reduced-motion` |
| 适用 | 营销落地页、产品故事页 |
| 禁用 | 企业监控、管理界面 |
| 落地检查 | 每个动效有语义？出场快于入场？reduced-motion 支持？ |

### 20 Aurora & Gradient Mesh

| 项 | 内容 |
|----|------|
| 特征 | 网格渐变、流动色带、氛围光 |
| 色彩 | 互补色对（蓝橙/紫黄）或同色相多档；**只作背景层，不用于 UI 元素** |
| 排版 | 文字必须压在纯色或深遮罩上，保证 4.5:1 |
| 形状 | 形状中性；渐变是唯一装饰 |
| 间距 | 宽松 |
| 动效 | 缓慢循环（8–12s），**必须尊重 reduced-motion** |
| **差异化抓手** | **渐变的色彩组合必须来自品牌**——不是紫粉，而是「你这个产品专属的两色」 |
| **AI 味陷阱** | ① **AI 最爱的默认背景**（紫→粉 → 蓝→紫）→ **必须换成品牌专属色对** ② 渐变上直接压文字 → 必须加遮罩 ③ 用于数据区 → 干扰读数 |
| 适用 | 营销落地页 Hero、品牌页 |
| 禁用 | 数据密集、管理界面 |
| 落地检查 | 色对是否品牌专属？文字是否加遮罩？是否只作背景？ |

## F 组 · 平台合规

### 21 Accessible & Ethical

| 项 | 内容 |
|----|------|
| 特征 | 高标准对比、大字号、键盘优先、语义化、全场景安全 |
| 色彩 | 对比 **≥7:1**（增强目标）；不依赖颜色传信息；背景纯色 |
| 排版 | 正文 **≥16px**；行高 1.6–1.75；行宽 60–75 字符 |
| 形状 | 焦点环 3–4px 且**高对比**；形状不承载信息 |
| 间距 | 触控目标 ≥44×44pt；间距 4/8 基数 |
| 动效 | 默认克制；完整支持 `prefers-reduced-motion` 与动态字号 |
| **差异化抓手** | **字号的极端层级 + 极简的形态**——因为颜色不能承担语义，必须靠排版 |
| **AI 味陷阱** | ① 被视为「不好看」而被改回低对比 → **这是纪律，不是 AI 味** ② 只满足最低标准（4.5:1）→ 目标应是 7:1 |
| 适用 | **全场景**（唯一无禁用的风格） |
| 禁用 | 无 |
| 落地检查 | 对比 ≥7:1？正文 ≥16px？键盘全通？色非唯一指示？ |

### 23 Fluent 2

### 24 Spatial UI (VisionOS)

| 项 | 内容 |
|----|------|
| 特征 | 空间层级、玻璃材质、深度映射、注视交互 |

| **差异化抓手** | **真实的 Z 轴层级**——元素在空间中前后关系明确，而非平面堆叠 |
| **AI 味陷阱** | ① 只是「玻璃 + 圆角」的扁平复制 → **必须有真实的深度关系** ② 无键盘/非注视替代方案 → 无障碍失败 |
| 适用 | 空间计算应用、概念展示 |
| 禁用 | 数据密集、管理界面 |
| 落地检查 | Z 轴关系是否明确？是否有非注视的替代交互？ |

## 附：跨风格的通用检查

无论选哪种风格，以下四项都必须成立：

1. **差异化抓手只有 1 个。** 两次「重点」等于没有重点。
2. **AI 味陷阱小节逐条自查过。** 每种风格的陷阱都是它最容易失守的地方。
3. **误杀清单过了一遍。** 见 `../anti-ai/false-positives.md`。
4. **六态齐全 + 对比度达标 + reduced-motion 支持。** 这三项与风格无关。
