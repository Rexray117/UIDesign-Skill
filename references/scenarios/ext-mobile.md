# 场景处方 · C 端移动端（扩展）

> H5、小程序、移动 App 的 Web 层、响应式产品的移动形态

## 一、定位

**拇指可达、单手可完成、弱网可降级、平台原生感。**

判据：**首屏任务完成率** 与 **误触率**，两者由触控目标尺寸与拇指热区直接决定。

---

## 二、使用者与情境

| 项 | 典型答案 |
|----|----------|
| 谁 | 移动场景用户；注意力分散 |
| 何时 | 碎片化、走动中、通勤、可能单手操作 |
| 何地 | 各种光照条件；网络不稳定 |
| 首要目标 | 快速完成一个动作 |
| 次要目标 | 不丢失已填内容 |

**三条物理约束**（不可协商）：
1. 触控目标 ≥44×44pt（iOS）/ ≥48×48dp（Android）
2. 目标间距 ≥8px
3. 拇指热区决定主要操作位置

---

## 三、设计重心（五条，按优先级）

1. **拇指可达。** 主操作必须在屏幕下半部/下缘；顶部只放标题与次要信息。
2. **触控目标足够大。** 视觉可以小，**热区必须大**（用 padding 扩展）。
3. **平台原生感。** 遵循平台惯例（导航、返回手势、控件形态），不重新发明。
4. **弱网兜底。** 加载、超时、离线、重试都必须有明确出口。
5. **不丢输入。** 表单自动保存草稿，返回不重置。

---

## 四、推荐风格与旋钮

| 首选 | 22 Material 3 Expressive（Android 感） / 02 Flat Design / 03 Bento Box Grid |
|------|------------------------|
| 次选 | 10 Liquid Glass（iOS 语境） / 13 Claymorphism（亲和向） |
| 保守 | 21 Accessible & Ethical |

```
--variance 5    （移动端屏幕窄，非对称空间有限）
--motion   5    （转场需要连续性，但不得阻塞输入）
--density  4    （触控需要呼吸；密集 = 误触）
```

> ⚠️ **移动端不要把 density 调到 7 以上。** 密集与触控目标冲突，会直接导致误触。

## 五、关键规格

### 5.1 触控与拇指热区

| 项 | 规格 |
|----|------|
| 触控目标 | **≥44×44pt（iOS）/ ≥48×48dp（Android）** |
| 目标间距 | ≥8px |
| 视觉小目标 | 图标可 24px，但热区必须扩展到 44/48 |
| 拇指热区 | 屏幕下 1/3 为易达区 → 放主操作；上 1/3 为难达区 → 只放标题与信息 |
| 危险操作 | **不得放在拇指易误触的位置**（如底部边缘） |
| 手势 | 一个区域一个主手势；不与系统手势冲突 |
| 滑动 | 不得与主内容横向滑动冲突；滑动操作需有可见提示 |

### 5.2 排版

| 元素 | 规格 |
|------|------|
| 正文 | **≥16px**（低于 16px 触发 iOS 自动缩放，页面会跳） |
| 行高 | 1.5–1.75 |
| 行宽 | 35–60 字符 |
| 输入框高度 | **≥44px** |
| 字重 | 400 / 500 / 600 |
| 动态字号 | 必须支持系统字号放大且不截断、不破版 |

### 5.3 布局

| 项 | 规格 |
|----|------|
| 设计基准 | 375px（小屏必须验证）；另测 320 / 390 / 414 / 428 |
| 安全区 | 使用 `env(safe-area-inset-*)`；固定栏必须避让刘海与手势条 |
| 视口单位 | 用 `min-h-dvh` 而非 `100vh`（避免移动端地址栏导致的跳变） |
| 固定元素 | 吸底栏/吸顶栏必须为内容预留内边距，**不得遮挡内容** |
| 横向滚动 | 禁止出现 |
| 缩放 | **不得禁用缩放**（无障碍） |
| 方向 | 横屏下仍需可用 |

### 5.4 导航（平台惯例）

| 平台 | 结构 |
|------|------|
| iOS | 底部 Tab Bar 承载顶层导航；顶部导航栏含返回 |
| Android | 顶部 App Bar + 导航图标；底部导航 ≤5 项 |
| 通用 | 底部导航 **≤5 项，且必须有图标 + 文字**（纯图标伤害可发现性） |
| 抽屉 | 只用于次级导航，不放主要动作 |
| 返回 | 必须可预期；系统返回手势不得被拦截 |
| 状态保留 | 返回时必须恢复滚动位置、筛选与输入 |

### 5.5 反馈与状态

| 项 | 规格 |
|----|------|
| 按压反馈 | ≤100ms，用 ripple / 透明度 / 层级，**不改变布局边界** |
| 触感反馈 | 仅用于确认与重要操作，不过度使用 |
| 加载 | >1s 用骨架屏；**不用长期阻塞的 spinner** |
| 输入延迟 | 点击/滚动反馈 <100ms |
| 提交 | 提交中禁用按钮 + spinner；失败保留输入 |
| 弱网 | 降级模式（低清图、少动效）+ 明确提示 |
| 离线 | 明确离线态 + 基础可用降级 |

### 5.6 表单（移动端特有）

| 项 | 规格 |
|----|------|
| 输入类型 | 用语义化 type（`email` / `tel` / `number`）触发正确键盘 |
| 自动填充 | 支持 `autocomplete` / `textContentType` |
| 密码 | 提供显示/隐藏切换 |
| 校验 | onBlur，错误就近显示并 `aria-describedby` 关联 |
| 自动保存 | 长表单自动保存草稿 |
| 关闭确认 | 有未保存改动时，关闭前确认 |
| 键盘遮挡 | 聚焦时把字段滚入可视区，**不得被键盘遮挡** |

## 六、本场景的 AI 味与误杀

### 6.1 真正的 AI 味（要改）

| 症状 | 改造 |
|------|------|
| 桌面布局直接缩到窄屏（三列变一列但间距未调） | 按移动端重新设计：单列、增大间距、底部操作栏 |
| 大圆角卡片 + 柔和阴影堆叠 | 圆角收敛；阴影 ≤1 档 |
| 顶部塞满操作按钮（拇指够不到） | 主操作移到拇指热区 |
| 加载用全屏 spinner 转圈 | 换骨架屏 |
| emoji 当图标 | 换同族 SVG 图标（移动端尤其明显） |
| 「标题 + 三卡片」的移动版默认骨架 | 按内容决定；用列表替代 |
| 无按压反馈（依赖 hover） | 换为按压态；触屏无 hover |

### 6.2 误杀（不许改）

| 会被误判 | 为什么不能改 |
|----------|-------------|
| 16px 正文 + 较大行高 | 低于 16px 会触发 iOS 自动缩放 |
| 单列纵向流 | 窄屏的唯一合理布局 |
| 大内边距 / density 低 | 触控目标需要呼吸；密集 = 误触 |
| 底部 Tab Bar | 平台惯例 |
| **无 hover 态** | 触屏本就无 hover，**不需要补** |
| 大面积留白 | 触控与聚焦需要 |
| 顶部只放标题（操作在下） | 拇指可达性的要求，不是「浪费空间」 |
| 吸底栏 | 主操作的合理位置 |

> **判定口令**：**「单手握住手机，拇指能不能够到主操作？会不会误触？」**

## 七、检查清单

**触控**
- [ ] 所有触控目标 ≥44pt（iOS）/ ≥48dp（Android）
- [ ] 目标间距 ≥8px
- [ ] 小图标的热区已扩展到 44/48
- [ ] 主操作位于拇指热区（屏幕下 1/3）
- [ ] 危险操作不在易误触位置
- [ ] 按压反馈 ≤100ms 且不引起布局位移
- [ ] 无嵌套/冲突手势；系统手势未被拦截

**排版与布局**
- [ ] 正文 ≥16px；输入框高度 ≥44px
- [ ] 支持系统字号放大且不截断
- [ ] 375px 下无横向滚动
- [ ] 未禁用缩放
- [ ] 固定栏避让安全区（`env(safe-area-inset-*)`）
- [ ] 用 `dvh` 而非 `vh`
- [ ] 吸底/吸顶栏未遮挡内容
- [ ] 横屏可用

**导航**
- [ ] 遵循平台惯例（iOS Tab Bar / Android App Bar）
- [ ] 底部导航 ≤5 项且图标 + 文字
- [ ] 返回行为可预期，系统返回手势可用
- [ ] 返回时恢复滚动位置与输入

**状态与容错**
- [ ] >1s 加载用骨架屏
- [ ] 空 / 错误 / 离线 / 禁用四态齐全
- [ ] 弱网有降级模式
- [ ] 表单自动保存草稿
- [ ] 有未保存改动时关闭需确认
- [ ] 聚焦时字段不被键盘遮挡
- [ ] 关键操作有触感反馈（不过度）

**无障碍**
- [ ] 对比 ≥4.5:1（大字 ≥3:1）
- [ ] 支持 `prefers-reduced-motion`
- [ ] 语义化标签与 `aria-label`
- [ ] 屏幕阅读器焦点顺序与视觉一致
- [ ] 拖拽/滑动操作有按钮替代
