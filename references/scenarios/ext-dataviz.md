# 场景处方 · 数据可视化大屏（扩展）

> 指挥中心大屏、汇报大屏、数字孪生、展览展示屏

## 一、定位

**在 3–8 米外，让一屋子人在 10 秒内看懂此刻的状态。**

判据：**远距离可读性** 与 **叙事顺序**，而不是信息总量。

---

## 二、使用者与情境

| 项 | 典型答案 |
|----|----------|
| 谁 | 决策者、参观者、汇报对象、指挥人员 |
| 何时 | 会议中、汇报时、值守时 |
| 何地 | **大屏（1920–7680px 宽）**；观看距离 3–8 米；常为横向多屏拼接 |
| 首要目标 | 一眼掌握全局与异常 |
| 次要目标 | 支撑汇报叙事、形成视觉说服力 |

**与管理界面/监控界面的关键区别**：
- 监控界面：**近距、长时间、个体操作** → 高密度
- 数据大屏：**远距、短时间、群体观看** → 低密度、大字号、强层次

> **把监控界面的密度直接搬到大屏上，是最常见的本场景错误。**

---

## 三、设计重心（五条，按优先级）

1. **远距离第一。** 最小可视字号按距离反推；宁少勿小。
2. **一屏一个结论。** 大屏是「结论展示」不是「数据分析」。分析在后台做。
3. **叙事有顺序。** 视线路径必须被设计（左上 → 右上 → 中 → 下），而不是均匀平铺。
4. **视觉层级极端化。** 主指标与其他元素的对比要 5× 以上。
5. **零交互或极简交互。** 大屏通常无人操作；若需交互，用远程控制并提供自动轮播的安全回退。

---

## 四、推荐风格与旋钮

| 首选 | 05 Data-Dense Dashboard（内容层） / 06 Dark Mode (OLED)（大屏环境） |
|------|------------------------|
| 次选 | 08 HUD Sci-Fi FUI（指挥/监控语境） / 20 Aurora（仅背景，克制） |
| 骨架 | 02 Flat Design |

```
--variance 4    （稳定布局，但允许主指标偏置）
--motion   4    （数据更新 + 极克制的背景流动；无装饰动画）
--density  8    （相对监控界面略降，因观看距离）
```

## 五、关键规格

### 5.1 字号（按观看距离反推）

| 距离 | 最小字号 | 主指标字号 | 说明 |
|------|:--------:|:----------:|------|
| 3–4 m | 18px | 48–72px | 会议室 |
| 4–6 m | 24px | 72–120px | 指挥中心 |
| 6–8 m | 32px | 120–200px | 展厅/大厅 |

**通用经验**：每增加 1 米观看距离，字号至少增加 25%。
**禁止**：任何小于 18px 的文字上大屏。

### 5.2 色彩（暗色环境）

| 项 | 规格 |
|----|------|
| 底色 | 深色（`#000`–`#0B1220`）；减少屏幕溢光 |
| 主色 | 1 个高饱和功能色（青/蓝绿） |
| 状态色 | 正常/警告/严重，全屏唯一映射；**必须配图标或形状** |
| 对比 | 文字 ≥7:1 |
| 发光 | 仅用于边界与活跃态，**≤2 处** |
| 禁止 | 大面积浅色底（远看刺眼）、装饰渐变、同屏 >4 色相 |

> **远距离下色彩对比会衰减**：手机上看够用的对比，10 米外可能糊成一片。**按最远距离测试。**

### 5.3 布局

| 项 | 规格 |
|----|------|
| 画布 | 常见 1920×1080 / 3840×2160；**必须锚定基准分辨率再等比缩放** |
| 安全边距 | 屏体边框遮挡 ≥32px；拼接屏接缝额外避让 |
| 分区 | 3–5 个区块，不超过 6 个 |
| 主指标区 | 居中或左上，**跨区最大** |
| 内边距 | 区块内 24–48px（远看需要更大的呼吸） |
| 禁止 | 内容贴屏边；跨接缝放关键信息 |

### 5.4 图表选择（大屏专用约束）

| 约束 | 说明 |
|------|------|
| 图表数 | 一屏 ≤6 个 |
| 数据点 | 单图 ≤50 个点（远看更少更清） |
| 图表类型 | 折线（趋势）/ 柱形（对比）/ 环形（占比 ≤5 类）/ 地图（地理）/ 仪表（目标达成） |
| 禁止 | 饼图（>5 类）、3D 图表、堆叠过深的堆叠图、密集散点 |
| 标注 | 关键值**直接标在图上**（减少视线来回）；图例就近放置 |
| 动画 | 仅数据更新时；**禁止无限循环的装饰动画** |

详见 `../quality/charts.md`。

### 5.5 刷新与数据可信

| 项 | 规格 |
|----|------|
| 刷新频率 | 按业务定，但**必须显示「最后更新时间」** |
| 陈旧提示 | 超过阈值必须变色或显示告警 |
| 无数据 | 显示明确文字，**不得留空**（空白与「0」无法区分） |
| 布局稳定 | 数值变化不得引起布局位移（等宽数字 + 固定宽度） |
| 时区 | 必须明确标注 |

## 六、本场景的 AI 味与误杀

### 6.1 真正的 AI 味（要改）

| 症状 | 改造 |
|------|------|
| 「深色底 + 发光边框卡片 + 彩色圆环图 × 8」的模板大屏 | 拆掉发光边框；圆环降到 ≤2 个；其余改柱形/数字 |
| 装饰性扫描线、雷达波、粒子、网格背景蔓延全屏 | 删除，或限制在 1 个无数据区域 |
| 所有指标等大等重，无主次 | 主指标字号跳档到 5× 以上且跨区 |
| 紫蓝渐变背景 | 换纯深色（远看更清晰） |
| 无限循环的图表动画 | 删除，仅在数据更新时动 |
| 图表配色任意（红绿蓝黄全上） | 收敛到 1 功能色 + 状态色 |
| 数字在刷新时做长度动画 | 直接切换，避免闪烁干扰读数 |

### 6.2 误杀（不许改）

| 会被误判 | 为什么不能改 |
|----------|-------------|
| 超大字号 | 远距离必需 |
| 低信息量（一屏只有 4–6 个数） | 大屏是结论展示，不是分析工具 |
| 深色底 | 减少屏幕溢光，展厅标准 |
| 均匀平铺的分区 | 稳定布局便于反复扫视 |
| 大内边距 | 远看的呼吸需求 |
| 饱和度较低的功能色 | 长时间观看的舒适性 |
| 无交互控件 | 大屏常无人操作 |
| 装饰性但**克制**的品牌元素（Logo、边界） | 品牌识别需要 |

> **判定口令**：**「退到 6 米外，还能看清主指标和异常吗？」**

## 七、检查清单

**远距可读**
- [ ] 最小字号 ≥18px（按距离反推，6m 以上 ≥32px）
- [ ] 主指标字号 ≥48px 且与其他元素对比 ≥5×
- [ ] 文字对比 ≥7:1，且在**最远距离实测过**
- [ ] 区块数 ≤6

**叙事与层次**
- [ ] 一屏只有一个结论
- [ ] 视线路径有设计（非均匀平铺）
- [ ] 主指标区居中或左上且跨区最大
- [ ] 关键值直接标在图上

**色彩纪律**
- [ ] 深色底，无大面积浅色
- [ ] 同屏色相 ≤4；发光 ≤2 处且都有语义
- [ ] 状态色全屏唯一映射 + 配图标/形状（色盲安全）
- [ ] 无装饰性循环动画

**工程**
- [ ] 锚定基准分辨率，等比缩放验证过
- [ ] 安全边距避让屏体边框与拼接接缝
- [ ] 显示「最后更新时间」+ 时区
- [ ] 无数据态有明确文字
- [ ] 数值刷新不引起布局位移

**无障碍（若为公共展示）**
- [ ] 支持 `prefers-reduced-motion`
- [ ] 提供可导出/可打印的静态版供无法观看者获取信息
