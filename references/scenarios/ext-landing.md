# 场景处方 · 营销落地页（扩展）

> 产品官网、活动页、定价页、招聘页、Webinar 报名页

## 一、定位

**在 5 秒内让人明白「这是什么、给谁的、为什么现在要行动」。**

判据：转化率，不是美观度。所有视觉决策都要能回答「这如何提升转化」。

---

## 二、使用者与情境

| 项 | 典型答案 |
|----|----------|
| 谁 | 潜在客户；**可能完全不认识你** |
| 何时 | 3–30 秒的注意力窗口；可能从广告/搜索一跳而来 |
| 何地 | 移动端占比常 >60% |
| 首要目标 | 判断「这跟我有关吗」 |
| 次要目标 | 点击 CTA |

---

## 三、设计重心（五条，按优先级）

1. **首屏自证。** 首屏必须独立回答「是什么 + 给谁 + 下一步」，不能靠滚动才说清。
2. **一个 CTA。** 全页指向同一个动作；次要动作视觉上明显降级。
3. **具体优于漂亮。** 数字、截图、真实客户，胜过一切形容词。
4. **为移动端先设计。** 60% 的流量在窄屏上做决策。
5. **允许强表达。** 这是唯一可以「大胆」的场景——但大胆必须集中在一处。

---

## 四、推荐风格与旋钮

| 首选 | 03 Bento Box Grid / 04 Editorial Grid / 17 Brutalism & Neubrutalism |
|------|------------------------|
| 次选 | 20 Aurora & Gradient Mesh（仅 Hero 背景） / 10 Liquid Glass / 14 Organic Biophilic |
| 保守选择 | 01 Swiss Minimalism |

```
--variance 7    （允许非对称与偏置）
--motion   6    （滚动显现 + 错峰；须支持 reduced-motion）
--density  3    （宽松，留白是资源）
```

> ⚠️ `--motion` 只在**滚动显现与错峰**层面使用。禁止「元素从四面八方飞入」。

## 五、关键规格

### 5.1 落地页模式（从 34 种中选 1）

先定结构模式，再定视觉。常用四种：

| 模式 | 版块顺序 | CTA 位置 | 适用 |
|------|----------|----------|------|
| **Hero + Features + CTA** | Hero > 价值主张 > 关键特性 3–5 > CTA 区 > 页脚 | Hero（吸顶）+ 底部 | 通用默认 |
| **Hero + Testimonials + CTA** | Hero > 问题陈述 > 方案概述 > 客户评价轮播 > CTA | Hero + 评价后 | 需要信任背书 |
| **Product Demo + Features** | Hero > 产品视频/模型（居中）> 逐节特性拆解 > 对比（可选）> CTA | 视频居中 + CTA 右侧 | 产品复杂度高 |
| **Minimal Single Column** | Hero 标题 > 简述 > 收益要点 ≤3 > CTA > 页脚 | 居中大 CTA | 单一功能产品 |

全 34 种见 `data/landing.csv`。

### 5.2 首屏（最重要的 600px）

| 项 | 规格 |
|----|------|
| 主标题 | ≤12 中文字；**必须含具体名词或数字**；行高 1.1–1.25，收紧字距 |
| 副标题 | ≤2 行；补充「给谁」与「能得到什么」 |
| CTA | **唯一主按钮**；文案说结果不说动作名 |
| 次行动 | 视觉降级为文字链（如「看 3 分钟演示」） |
| 视觉 | 真实产品截图 > 抽象插画；若用渐变，**色对必须来自品牌** |
| 移动端 | 首屏必须放下标题 + 副标题 + CTA（可能在折叠线以下，但滚动一次必须看到） |

### 5.3 排版

| 元素 | 规格 |
|------|------|
| Hero 标题 | 36–64px（桌面）/ 28–36px（移动） |
| 区块标题 | 24–32px |
| 正文 | 16px；行高 1.6 |
| 字号档 | ≥5 档，**最大/最小 ≥4×**（营销页可比用户界面更极端） |
| 字重 | 400 / 500 / 700（营销页可用更粗） |

### 5.4 色彩

| 项 | 规格 |
|----|------|
| 色相 | ≤3 + 中性 |
| 强调色 | 1 个，**且给 CTA** |
| 渐变 | 仅 Hero 背景，**色对品牌专属**；文字必须压遮罩 |
| 对比 | CTA 文字对按钮填充 **≥4.5:1** |
| 禁止 | 紫→粉 / 蓝→紫 渐变；同屏 >1 个强调色 |

### 5.5 社会证明

| 项 | 规格 |
|----|------|
| 形式 | 客户 Logo 墙 / 证言（带姓名职务头像）/ 数字指标 / 案例 |
| 真实性 | **不得编造**。无真实证言时用可验证的数字或产品截图替代 |
| 位置 | 主 CTA 之前 |
| 数量 | 证言 3–5 条（可轮播，但**必须可暂停**且不自动抢夺焦点） |

### 5.6 转化要素

| 项 | 规格 |
|----|------|
| CTA 出现次数 | 2–4 次（Hero + 中段 + 尾段），措辞一致 |
| 表单字段 | 越少越好；能后置的字段后置 |
| 价格 | 明确标价或明确说明「需询价」；不藏总价 |
| 风险降低 | 「不用绑卡」「随时取消」「14 天退款」 |
| 页面重量 | 首屏资源 <500KB；图片 WebP/AVIF + 懒加载 |

## 六、本场景的 AI 味与误杀

### 6.1 真正的 AI 味（要改）——**本场景风险最高**

| 症状 | 改造 |
|------|------|
| Hero 居中 + 紫蓝渐变 / 紫粉渐变背景 | 删渐变；改偏置布局；若保留渐变改用品牌专属色对 |
| 「标题 + 副标题 + 双按钮 + 三等分特性卡 × 6」标准套件 | 收敛到 3 个真实差异点 |
| 通用正向文案（Seamlessly / Empower / All-in-one / 开启旅程） | 换成具体事实与数字 |
| 抽象插画代替产品截图 | 换真实截图 |
| 每个区块都有入场动画 | 每屏 ≤2 个；出场快于入场（60–70%） |
| 全页圆角 20px + 柔和阴影 | 圆角收敛；阴影 ≤1 档 |
| 「值得信赖」类空话 | 换具体做法与可验证指标 |
| Bento 等大网格 | 必须跨列跨行 |

### 6.2 误杀（不许改）

| 会被误判 | 为什么不能改 |
|----------|-------------|
| 大面积留白 | 聚焦资源，营销页的必要条件 |
| 单一 CTA | 聚焦是刻意的 |
| 只有一个大标题 + 极少文字 | 首屏自证的需要 |
| 大字号（64px） | 强表达是刻意的 |
| 居中 Hero（若品牌/内容对称） | 对称在营销页合法 |
| 强对比色彩 | 转化需要 |
| 无复杂导航 | 减少出口，提升转化 |
| 短页脚 | 不是缺失 |

> **判定口令**：**「改了之后，5 秒内还能说清这是什么吗？CTA 还够显眼吗？」**

## 七、检查清单

**首屏自证**
- [ ] 首屏独立说清「是什么 + 给谁 + 下一步」
- [ ] 主标题含具体名词或数字，≤12 中文字
- [ ] 有且仅有 1 个主 CTA
- [ ] 有真实产品截图或明确的视觉证据

**转化**
- [ ] CTA 出现 2–4 次，措辞一致
- [ ] 社会证明在主 CTA 之前，且真实可验证
- [ ] 标价明确或明确说明询价
- [ ] 有风险降低表述
- [ ] CTA 文字对填充色 ≥4.5:1

**视觉纪律**
- [ ] 色相 ≤3；强调色 1 个且给 CTA
- [ ] 无紫粉渐变；渐变仅 Hero 且色对品牌专属
- [ ] 字号最大/最小 ≥4×
- [ ] Bento/网格有跨列跨行
- [ ] 无 emoji 当图标

**性能与无障碍**
- [ ] 首屏资源 <500KB；图片 WebP/AVIF + 懒加载
- [ ] 行宽 60–75 字符
- [ ] 键盘可完成主流程；焦点可见
- [ ] 支持 `prefers-reduced-motion`
- [ ] 自动轮播可暂停，聚焦时停止
- [ ] 表单字段有可见标签
- [ ] 375px 下无横向滚动
