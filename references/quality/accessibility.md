# 无障碍规范

> **定位**：无障碍是**优先级第一位**（在 UX 十类中排第 1，且所有 Critical 级规则都在此处）。
> 它是**设计纪律，不是 AI 味**——任何时候都不得以「简洁」「美观」为由削减。

---

## 一、对比度红线

| 元素 | 最低（AA） | 增强（AAA） |
|------|:---------:|:-----------:|
| 正文 | **4.5:1** | 7:1 |
| 大字号（18px+，或 14px+ 粗体） | 3:1 | 4.5:1 |
| UI 组件边界 | 3:1 | — |
| 焦点指示器 | 3:1 | — |
| 有语义的图标 | 3:1 | — |
| 图表数据线/柱 vs 背景 | 3:1 | — |
| 图表数据标签 | 4.5:1 | — |

**纪律**：
- 暗色模式**必须独立测试**，不得沿用亮色数值
- 禁用态也需 ≥3:1（不得完全不可见）
- 半透明表面上压文字时，**测的是合成后的实际对比**

## 二、焦点与键盘

| 规则 | 说明 |
|------|------|
| **焦点必须可见** | 环宽 2px（高对比场景 3–4px）；`focus-visible`；**绝不移除** |
| **焦点顺序** | 必须与视觉顺序一致 |
| **无键盘陷阱** | Tab 必须能进入并离开任何组件 |
| **粘性元素不遮挡焦点** | 吸顶栏/浮层不得盖住当前聚焦控件（用 `scroll-padding`） |
| **完整键盘支持** | 主流程可全键盘完成 |
| **跳过链接** | 提供「跳到主内容」 |
| **标题层级** | `h1` → `h6` 顺序，不跳级；页面只有一个 `h1` |
| **语义标签** | 使用 `header` / `nav` / `main` / `aside` / `footer` landmark |
| **快捷键** | 保留系统与辅助技术快捷键；拖拽提供键盘替代 |
| **路由切换** | 页面切换后把焦点移到主内容区 |

### 焦点环规格

```css
.focusable:focus-visible {
  outline: none;
  box-shadow:
    0 0 0 var(--ring-offset) var(--color-background),
    0 0 0 calc(var(--ring-offset) + var(--ring-width)) var(--color-ring);
}
```

| 属性 | 值 |
|------|-----|
| 环宽 / 偏移 | 2px / 2px |
| 环色 | 主色或高对比色 |
| 状态对比 | 焦点指示器本身与相邻色需 3:1 |

**额外要求（WCAG 2.2）**：
- 粘性 UI、浮层、横幅**不得隐藏**键盘聚焦的控件
- 增强级要求整个聚焦组件可见

## 三、触控与指针

| 规则 | 规格 |
|------|------|
| 触控目标（移动） | **≥44×44pt（iOS）/ ≥48×48dp（Android）** |
| 触控目标间距 | ≥8px |
| 热区扩展 | 视觉可小，**热区必须扩展到位** |
| Web 指针目标（WCAG 2.2 AA） | **≥24×24 CSS px**，或提供例外说明 |
| 禁止 | 要求像素级精确点击的细边/小图标 |
| 手势替代 | 拖拽/滑动必须有单指点击与键盘替代 |
| 手势冲突 | 避免与系统手势（返回、控制中心）冲突 |
| 拖拽阈值 | 设移动阈值防误拖 |

---

## 四、色彩与其他感知通道

| 规则 | 说明 |
|------|------|
| **颜色不得是唯一指示手段** | 必须配图标、形状、纹理或文字 |
| 状态色 | 必须配图标/形状（色盲安全） |
| 图表 | 用图案/纹理/形状区分系列，不只靠颜色 |
| 错误态 | 用图标 + 文字 + 颜色三重编码 |
| 链接 | 不用「仅颜色」与正文区分（加下划线或字重） |
| 极端色 | 避免红绿独对；避免低对比灰底灰字 |

---

## 五、表单无障碍

| 规则 | 规格 |
|------|------|
| 可见标签 | **每个输入必须有可见 `label`**（不用 placeholder 当标签） |
| `for` 关联 | `label` 用 `for` 属性关联控件 |
| 必填标识 | 明确标记（星号 + 文字说明） |
| 帮助文本 | 持久显示，不只靠 placeholder |
| 错误关联 | `aria-invalid="true"` + `aria-describedby` 指向错误文本 |
| 错误提示 | `role="alert"` 或 `aria-live` 播报 |
| 多错误 | **顶置可聚焦的错误摘要**，每项链接到对应字段；**保留行内错误** |
| 焦点管理 | 提交失败后聚焦错误摘要；无摘要则聚焦第一个无效字段 |
| 输入类型 | 语义化 `type`（`email` / `tel` / `number`）触发正确键盘 |
| 自动填充 | 支持 `autocomplete` / `textContentType` |
| 认证 | 允许密码管理器与粘贴；提供非认知型替代路径 |
| 重新输入 | 同一流程内不重复索取已提供的信息（除非必要） |
| 超时 | 超时必须提示并可延长/重试 |
| 撤销 | 破坏性或批量操作支持撤销 |

```html
<input aria-invalid="true" aria-describedby="err-1">
<span id="err-1" role="alert">手机号需要 11 位</span>
```

## 六、图标与图像

| 规则 | 说明 |
|------|------|
| 装饰性图标（旁边有可见文字） | **对无障碍树隐藏**（`aria-hidden="true"`） |
| 有意义图标（无等价文字） | 提供文本替代 |
| 图标控件 | 提供**可访问名称**（`aria-label`），并播报 selected / pressed / expanded 状态 |
| 图像 | 有意义的图给描述性 `alt`；纯装饰给 `alt=""` |
| 语义由用法决定 | **同一个图标名在不同组件中可以是装饰性、有意义或交互性的**——按用法判定，不按图标名判定 |
| 对比度 | 有语义图标 ≥3:1 |
| 动态图标 | 不得唯一依赖动画传达状态 |

---

## 七、动态内容与实时更新

| 场景 | 规则 |
|------|------|
| Toast / 提示 | **不得抢焦点**；用 `aria-live="polite"` |
| 计数/状态变化 | 作为**完整上下文短语**播报，不移动焦点 |
| 实时区域 | 使用一个恰当的 live/status region；必要时用原子更新 |
| 自动更新内容 | 提供暂停/停止控件；聚焦或 reduced-motion 时停止 |
| 加载状态 | 用 `aria-busy` 并播报 |

```html
<button aria-busy="true" aria-describedby="loading-text">
  <span id="loading-text" class="sr-only">正在保存…</span>
</button>
```

## 八、动效与阅读偏好

| 偏好 | 要求 |
|------|------|
| `prefers-reduced-motion` | **必须支持**，降级为静态或仅不透明度变化 |
| 闪烁 | **禁止 >3 次/秒**的闪烁 |
| 视差 | 尊重 reduced-motion，不引起眩晕 |
| 动态字号 / 系统字号放大 | 支持且**不截断、不破版** |
| 文本间距 | 用户覆盖行高与字距后仍可用 |
| 缩放 | **不得禁用缩放**（`user-scalable=no` / `maximum-scale=1` 禁止） |
| 内容重排 | 400% 缩放下仍可读（不要求横向滚动） |

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 九、内容与可读性

| 规则 | 说明 |
|------|------|
| 语言声明 | `html` 元素带 `lang` |
| 标题描述性 | 页面标题、区块标题都应说明内容 |
| 链接文案 | 「查看定价」优于「点击这里」 |
| 帮助一致性 | 重复的帮助机制在页面集合中保持相同相对顺序 |
| 错误清晰 | 说明「原因 + 怎么修」，不只写「输入无效」 |
| 缩写 | 首次出现给全称 |
| 时间 | 明确时区 |

## 十、无障碍自检

**对比与色彩**
- [ ] 正文 ≥4.5:1；大字与 UI ≥3:1
- [ ] 暗色模式独立测过
- [ ] 颜色不是唯一指示手段
- [ ] 状态色配了图标或形状
- [ ] 图表用图案区分系列

**键盘与焦点**
- [ ] 主流程可全键盘完成
- [ ] 焦点环可见且 ≥3:1 对比
- [ ] 焦点顺序与视觉顺序一致
- [ ] 无键盘陷阱
- [ ] 粘性元素与浮层不遮挡焦点
- [ ] 有跳到主内容的链接
- [ ] 路由切换后焦点移到主内容

**语义与结构**
- [ ] 页面只有一个 `h1`，标题不跳级
- [ ] landmark 标签齐全
- [ ] `html` 有 `lang`
- [ ] 表单控件都有 `label` 关联
- [ ] 装饰性图标对无障碍树隐藏
- [ ] 有语义图标有文本替代
- [ ] 图标控件有可访问名称与状态

**表单**
- [ ] 错误就近显示 + `aria-describedby` 关联
- [ ] 多错误有顶置摘要 + 焦点管理
- [ ] 必填已标识
- [ ] 支持自动填充与密码管理器
- [ ] 超时有提示

**偏好与适配**
- [ ] 支持 `prefers-reduced-motion`
- [ ] 支持系统字号放大且不破版
- [ ] 未禁用缩放
- [ ] 触控目标 ≥44pt / ≥24 CSS px
- [ ] 无 >3 次/秒 的闪烁
- [ ] 自动轮播可暂停
- [ ] toast 不抢焦点，用 `aria-live`
