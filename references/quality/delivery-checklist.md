# 交付前检查清单（canonical）

> 本清单是**唯一的交付闸门**。未逐项打勾，不得声称「已完成」。
> 分两部分：**流程性检查**（必须真做，不能只看代码）与**逐域检查**。

---

## 第一部分 · 流程性检查

- [ ] **G1 设计主张已填写**（目的 / 调性 / 约束 / 差异化，四问均有具体答案）
- [ ] **G2 风格决策已记录**（主风格 + 辅风格 + 旋钮 + 被否决候选及理由）
- [ ] **G4 自检脚本已跑过**：`python scripts/ai_flavor_audit.py <目录>`
- [ ] 六维评分已读，且**逐项清单**已处理（分数只用于定位）
- [ ] **误杀检查已做**：过完 `../anti-ai/false-positives.md`
- [ ] **在真浏览器里看过**（不是只读代码）
- [ ] 截图覆盖 **375 / 768 / 1024 / 1440** 四档
- [ ] **暗色模式独立看过一次**
- [ ] **弱网/慢速模拟下看过一次**
- [ ] 在 **`prefers-reduced-motion`** 开启状态下验证过
- [ ] 在**系统最大字号 / 动态字号**下验证过
- [ ] 键盘 **Tab 走完主流程**，含模态与表单
- [ ] 控制台无错误与警告（常能解释视觉 bug）

---

## 第二部分 · 去 AI 味（本技能包的核心）

### D1 对称惯性
- [ ] 居中类声明占比 <30%
- [ ] 等宽列使用 ≤2 处，且均有理由
- [ ] 非对称结构 ≥3 处（跨列 / 偏移 / 尺寸对比）
- [ ] 阅读起点唯一
- [ ] 纵向留白有节奏（不是均匀分布）

### D2 色彩惰性
- [ ] 唯一色相 ≤3（不含中性灰）
- [ ] 强调色恰好 1 个
- [ ] 中性色 ≥4 档且层次分明
- [ ] 组件内无裸 hex
- [ ] 渐变均有合法理由（材质 / 深度 / 进度）
- [ ] **无紫粉色对**
- [ ] 同屏功能色仅用于状态

### D3 装饰过载
- [ ] 阴影档位 ≤3
- [ ] 圆角档位 ≤3
- [ ] 控件圆角 ≤ 表面圆角
- [ ] 无装饰性光晕
- [ ] hover 抬升只给可点击卡
- [ ] 区块间距 ≥ 内部间距 ×3
- [ ] 每条装饰都能回答「删了会损失什么信息」

### D4 排版扁平
- [ ] 字号档数 ≥5，且最大/最小 ≥3.5×
- [ ] 标题 ÷ 正文 ≥2.0×
- [ ] 字重档数 ≥3（或 400/600 两档 + 字距补偿）
- [ ] 界面 chrome 未用 100–300 或 700+
- [ ] 行高按内容类型区分
- [ ] 大字号标题有字距处理
- [ ] 数字列用 `tabular-nums`

### D5 结构同构
- [ ] 相邻区块结构至少有一处不同
- [ ] 全站「标题+副标题+3卡片」≤2 处
- [ ] 空 / 加载 / 错误三态齐全
- [ ] 列表页与详情页骨架不同
- [ ] 单屏并列模块在场景范围内且**有唯一主卡**
- [ ] 走完了「先内容后骨架」五步

### D6 语义空洞
- [ ] 无 emoji 承担图标职责
- [ ] 无空洞词（一站式 / 赋能 / 打造 / 智能的 / 极致的）
- [ ] 无通用积极收尾（开启旅程 / 解锁可能）
- [ ] 每个标题含具体名词或数字
- [ ] **替换测试通过**（换到竞品身上不成立）
- [ ] 按钮文案说结果而非动作名
- [ ] 空状态说清原因 + 下一步
- [ ] 错误提示说清原因 + 怎么修

---

## 第三部分 · 视觉质量

- [ ] 无 emoji 当图标
- [ ] 图标全站同族、同线宽、同尺寸体系
- [ ] 品牌资产使用正确（比例、留白、配色）
- [ ] 按下态不改变布局边界、不抖动
- [ ] 语义 token 一致使用，无逐屏硬编码
- [ ] 主题色全站唯一，未出现「第二套主色」
- [ ] 一致性：同一元素在任意页面表现相同
- [ ] 无「单页特例样式」

---

## 第四部分 · 交互

- [ ] 所有可点击元素有明确按下反馈（≤100ms）
- [ ] 触控目标 ≥44×44pt（iOS）/ ≥48×48dp（Android）
- [ ] 触控目标间距 ≥8px
- [ ] 微交互时长使用共享 token，响应及时
- [ ] 禁用态视觉清晰且不可交互（原生 `disabled`）
- [ ] 只读与禁用在视觉与语义上可区分
- [ ] 加载态：按钮禁用 + 指示器，宽度不变（防抖动）
- [ ] 屏幕阅读器焦点顺序与视觉顺序一致
- [ ] 手势区域无嵌套/冲突
- [ ] 动画可被用户操作中断
- [ ] 状态正确性不依赖动画结束事件

---

## 第五部分 · 明暗模式

- [ ] 两种模式下正文对比均 ≥4.5:1
- [ ] 两种模式下分隔线/边框均可区分
- [ ] 两种模式下交互态均可区分
- [ ] 暗色**不是简单反转**（已去饱和、重设边框）
- [ ] 模态遮罩经实测，前景可读
- [ ] 两种主题都实际看过（不是只推断）

---

## 第六部分 · 布局

- [ ] 375 / 768 / 1024 / 1440 均验证
- [ ] 横屏下可用
- [ ] 无横向滚动
- [ ] 安全区已适配（`env(safe-area-inset-*)`）
- [ ] 移动端用 `dvh` 而非 `vh`
- [ ] 固定栏为内容预留内边距，未遮挡内容
- [ ] 水平内边距随断点自适应
- [ ] 4/8 间距节奏在组件 / 区块 / 页面三级一致
- [ ] 长文行宽可读（60–75 字符；移动 35–60）
- [ ] z-index 走尺度

---

## 第七部分 · 无障碍

- [ ] 正文 ≥4.5:1；大字与 UI ≥3:1
- [ ] 颜色不是唯一指示手段
- [ ] 状态色配了图标 / 形状
- [ ] 全键盘可达，无键盘陷阱
- [ ] 焦点环可见（2–4px）且 ≥3:1 对比
- [ ] 粘性元素与浮层不遮挡焦点
- [ ] 有跳到主内容的链接
- [ ] 单一 `h1`，标题不跳级，landmark 齐全
- [ ] `html` 有 `lang`
- [ ] 装饰性图标对无障碍树隐藏
- [ ] 有语义图标有文本替代
- [ ] 图标控件有可访问名称并播报状态
- [ ] 表单有可见标签、提示与就近错误
- [ ] 多错误有顶置摘要 + 焦点管理 + 保留行内错误
- [ ] 支持 `prefers-reduced-motion`
- [ ] 支持系统字号放大，不截断不破版
- [ ] 未禁用缩放
- [ ] 拖拽/滑动有按钮或键盘替代
- [ ] 认证允许密码管理器与粘贴
- [ ] 自动轮播有暂停控件，聚焦或 reduced-motion 时停止
- [ ] toast 不抢焦点，用 `aria-live`

---

## 第八部分 · 性能

- [ ] 图片用 WebP/AVIF + 响应式 `srcset`
- [ ] 图与媒体声明尺寸或 `aspect-ratio`（防 CLS）
- [ ] 折叠线以下资源懒加载
- [ ] 字体用 `font-display: swap/optional`，仅预加载关键字体
- [ ] 首屏关键 CSS 优先
- [ ] 路由级代码分割
- [ ] 50+ 条目列表已虚拟化
- [ ] 高频事件已防抖/节流
- [ ] 第三方向脚本 async/defer，且已审计
- [ ] >1s 操作用骨架屏（非阻塞 spinner）
- [ ] >10s 提供进度与取消
- [ ] 首屏资源体积在场景预算内（营销页 <500KB）

## 第十部分 · 误杀复核（强制）

逐条确认**没有砍掉**以下内容：

- [ ] 六态完整性（未为「简洁」删状态）
- [ ] 焦点环（未为「干净」移除）
- [ ] 空 / 加载 / 错误态
- [ ] 触控目标尺寸
- [ ] 对比度标准
- [ ] 语义标签与 aria
- [ ] `prefers-reduced-motion` 支持
- [ ] 全站一致性
- [ ] 间距尺度纪律
- [ ] 主题与状态色语义化
- [ ] 场景性正确特征（如监控界面的密度、管理界面的对称）

**若发现砍掉了任一项，立即恢复。**
