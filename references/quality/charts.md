# 图表与数据可视化规范

---

## 一、图表选型（按数据类型）

| 数据类型 | 首选图表 | 备选 | 何时用 |
|----------|----------|------|--------|
| 随时间变化的趋势 | **折线图** | 面积图、流式面积图 | 时间序列 |
| 类别比较 | **柱形图（横/竖）** | 条形图、分组柱形 | 离散类别 |
| 部分与整体 | **饼图 / 环形图** | 华夫图、旭日图 | **仅当 ≤5 个类别** |
| 相关性 / 分布 | **散点图 / 气泡图** | 箱线图 | 两变量关系 |
| 热力 / 强度 | **热力图 / 等值线图** | 日历热力 | 二维密度 |
| 地理数据 | **等值线地图 / 气泡地图** | 点图 | 空间分布 |
| 漏斗 / 流向 | **漏斗图 / 桑基图** | 流程地图 | 转化与流转 |
| 绩效 vs 目标 | **仪表盘 / 子弹图** | 进度条 | 达标情况 |
| 时序预测 | **带置信区间的折线** | — | 预测 |
| 异常检测 | **带高亮的折线** | — | 异常标注 |
| 层级 / 嵌套 | **树图（Treemap）** | 旭日图 | 层级占比 |
| 累积变化 | **瀑布图** | — | 贡献分解 |
| 多变量对比 | **雷达图** | 平行坐标 | ≤6 维度 |
| 股票 OHLC | **K 线图** | — | 金融行情 |
| 关系 / 连接 | **网络图** | — | 拓扑 |
| 分布 / 统计 | **箱线图** | 小提琴图 | 统计分布 |
| 根因分析 | **分解树** | — | 归因 |

**全 25 种**见 `data/charts.csv`（含无障碍等级与降级方案）。

---

## 二、选型的四条硬规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | **饼图 / 环形图 >5 类 → 换柱形图** | 超过 5 类人眼无法比较角度 |
| 2 | **1000+ 数据点 → 聚合或采样 + 下钻** | 不渲染全部 |
| 3 | **时间序列必须标注时间粒度** | 日/周/月，且允许切换 |
| 4 | **不用 3D 图表** | 透视畸变损害读数准确性（唯一例外：3D 空间数据本身） |

## 三、色彩

| 项 | 规格 |
|----|------|
| **UI 保持中性** | 色彩预算留给数据（管理与监控场景尤其） |
| 数据线/柱 vs 背景 | **≥3:1** |
| 数据标签文字 | **≥4.5:1** |
| 分类色板 | ≤8 色，**且不得用于主操作** |
| 顺序色板 | 同色相多档明度（表达强度/热力） |
| 发散色板 | 双色相（表达正负偏离），中点用中性 |
| **禁止红绿独对** | 色盲不可辨；必须叠加形状或图案 |
| 状态色 | 成功/警告/错误；**必须配图标或形状** |

### 色盲安全

**颜色不能是唯一区分手段。** 必须叠加：

| 手段 | 方式 |
|------|------|
| 图案 / 纹理 | 斜线、点阵、网格 |
| 形状 | 圆点 / 方块 / 三角 |
| 线型 | 实线 / 虚线 / 点线 |
| 直接标注 | 在数据点旁标系列名 |

## 四、必备元素

| 元素 | 要求 |
|------|------|
| **图例** | 始终显示；**靠近图表**，不得放在折叠线以下 |
| **Tooltip** | hover（Web）或 tap（移动）显示精确值；**可键盘触达** |
| **坐标轴标签** | 有单位与可读刻度；移动端不截断/不旋转标签 |
| **数据表格替代** | 提供表格让屏幕阅读器可读 |
| **文字摘要** | 用 `aria-label` 或文字描述图表的关键结论 |
| **空数据态** | 「暂无数据」+ 引导，**不留空图表** |
| **加载态** | 骨架屏占位，**不显示空坐标轴** |
| **错误态** | 明确错误 + 重试，**不显示破图** |
| **最后更新时间** | 实时数据必须显示 |

---

## 五、可读性

| 项 | 规格 |
|----|------|
| 网格线 | **低对比**（如灰 200），不与数据竞争 |
| 刻度 | 不拥挤；小屏自动跳过刻度 |
| 小数据集 | **直接在图上标值**，减少视线来回 |
| 数据密度 | 单图限制信息量；过多则拆成多图 |
| 趋势强调 | 强调数据而非装饰；**避免遮挡数据的重渐变/阴影** |
| 数字格式 | 按区域格式化数字、日期、货币 |
| 轴起点 | 柱形图**必须从 0 开始**；折线图可不从 0（需标注） |

---

## 六、交互

| 交互 | 规格 |
|------|------|
| **图例可点击** | 切换系列显隐 |
| **下钻** | 保持清晰返回路径与层级面包屑 |
| 交互点触控 | ≥44pt，或触摸时扩展热区 |
| 键盘可达 | 交互元素（点/柱/扇）可键盘导航；Tooltip 可键盘触达 |
| 筛选联动 | 提供筛选让用户在全局与细节间切换 |
| 导出 | 数据密集产品提供 CSV / 图片导出 |
| 动画 | 入场动画尊重 `prefers-reduced-motion`；**数据应立即可读** |

---

## 七、大屏与远距场景（补充约束）

| 项 | 规格 |
|----|------|
| 图表数 | 一屏 ≤6 个 |
| 单图数据点 | ≤50 个 |
| 图表类型 | 折线 / 柱形 / 环形（≤5 类）/ 地图 / 仪表 |
| 禁止 | 饼图（>5 类）、3D 图表、深堆叠图、密集散点 |
| 标注 | 关键值直接标在图上 |
| 动画 | **禁止无限循环的装饰动画** |
| 对比 | 数据 vs 背景 ≥3:1，且需在**最远观看距离实测** |

---

## 八、与场景的配合

| 场景 | 图表策略 |
|------|----------|
| 企业监控界面 | 数字 + 迷你趋势线为主；图表只用于趋势与异常；**UI 中性** |
| 管理界面 | 表格优先；图表用于概览与对比；可提供导出 |
| 数据大屏 | 少而大；直接标值；无装饰动画 |
| 用户界面 | 图表从简；强调「用户能得出什么结论」 |
| 营销落地页 | 图表承担说服力；**数据必须真实可验证** |

## 九、图表自检

- [ ] 图表类型匹配数据类型
- [ ] 饼图/环形 ≤5 类
- [ ] 1000+ 点已聚合或采样 + 有下钻
- [ ] 时间序列标注了粒度并允许切换
- [ ] 无 3D 图表
- [ ] 图例存在且靠近图表
- [ ] Tooltip 可键盘触达
- [ ] 坐标轴有单位与可读刻度
- [ ] 数据 vs 背景 ≥3:1；标签 ≥4.5:1
- [ ] 有图案/形状补充颜色（色盲安全）
- [ ] 无红绿独对
- [ ] 提供表格替代与文字摘要
- [ ] 空 / 加载 / 错误三态齐全
- [ ] 实时数据有「最后更新时间」
- [ ] 网格线低对比
- [ ] 柱形图从 0 开始
- [ ] 入场动画尊重 reduced-motion
- [ ] 交互点触控 ≥44pt
- [ ] 图例可点击切换
- [ ] 数字格式已本地化
- [ ] 提供导出（数据密集产品）
- [ ] 数据真实，未编造
