# AI 味六维诊断

## 总纲

「AI 味」不是一串关键词，而是一种统计特征：**生成的界面高度收敛于训练数据的安全中心。**
表现为六维信号同时偏离「有人做过取舍」的分布。

本技能的每一条改造规则，都对应下面至少一个维度。

| 维度 | 名称 | 在衡量什么 | 人类设计师的表现 | 对应处方 |
|------|------|-----------|-----------------|----------|
| **D1** | 对称惯性 | 布局是否可被一次猜中 | 非对称、重心偏移、留白不均、刻意打破网格 | `fixes.md` §D1 |
| **D2** | 色彩惰性 | 配色是否有立场 | 受限色数、单强调色、有时不和谐但有意图 | `fixes.md` §D2 |
| **D3** | 装饰过载 | 是否每一处都在「加东西」 | 大量留白、只在一个元素上用力 | `fixes.md` §D3 |
| **D4** | 排版扁平 | 层次对比是否够狠 | 极端字号对比、字重与字距做层次 | `fixes.md` §D4 |
| **D5** | 结构同构 | 每屏是否长得一样 | 内容决定结构、不同页面骨架不同 | `fixes.md` §D5 |
| **D6** | 语义空洞 | 文案是否说了等于没说 | 具体、有立场、有时笨拙的表述 | `fixes.md` §D6、`copy-tells.md` |

> **重要**：六维是「诊断信号」，不是「定罪证据」。
> 每个维度都有合法的例外——先读 `false-positives.md` 再动手。

---

## D1 · 对称惯性

### 在衡量什么

布局的**可预测性**。把界面缩略成灰度图，能否一次就猜出元素位置？

AI 生成倾向：`text-align: center` 到处用、`justify-content: center` 是默认、三栏等宽、Hero 居中、卡片均分。

### 高危信号

| 信号 | 检测标准 | 严重度 |
|------|----------|--------|
| 居中密度过高 | 居中类声明占布局声明 > 45% | 高 |
| 等分栅格滥用 | 等宽列（`1fr 1fr 1fr` / `grid-cols-3`）出现 > 2 次 | 高 |
| 无不对称结构 | 全页无一处 `grid-column: span N` 或跨列 | 中 |
| 留白均匀 | 各区块上下间距完全相同，无节奏变化 | 中 |
| 对称 Hero | 标题居中 + 副标题居中 + 按钮居中 | 高（若为营销页） |

### 阈值备忘

- 居中声明占比 **< 30%** 为健康；30–45% 为可疑；> 45% 为高危
- 全站非对称结构（跨列/偏移/不等宽）**至少 3 处**

## D2 · 色彩惰性

### 在衡量什么

配色是否体现了**取舍**。取色越可预测，越像默认主题。

AI 生成倾向：主色落在 `#6366F1` / `#8B5CF6` / `#3B82F6`，紫粉渐变，色数膨胀到 8–12 个却不分主次。

### 高危信号

| 信号 | 检测标准 | 严重度 |
|------|----------|--------|
| 色相数过多 | 唯一色相 > 6 个（不含中性灰） | 高 |
| 紫粉渐变 | 出现 `purple`/`violet`/`indigo` → `pink`/`fuchsia` 的渐变 | 高 |
| 强调色过多 | 同屏出现 > 1 个强调色 | 高 |
| 硬编码色值 | 组件内裸 hex 数 > 0 | 高 |
| 渐变无理由 | `linear-gradient` 用于纯装饰（非表现材质/深度/进度） | 中 |
| 中性色缺层次 | 只有 1–2 档灰，无 4 档以上层级 | 中 |

### 阈值备忘

- 唯一色相（不含灰）**≤ 3** 为佳；4–6 可接受；> 6 高危
- 单强调色；功能色（成功/警告/错误/信息）不计入强调色
- 渐变只允许三种合法用途：**表现材质**（玻璃/液体）、**表现深度**（空间）、**表现进度/热力**（数据）

## D3 · 装饰过载

### 在衡量什么

是否**每一处都在用力**。装饰密度高 = 没有重点 = 没有取舍。

AI 生成倾向：阴影 + 圆角 + 渐变 + 光晕 + 边框 + 微动效全都上；每个卡片都有 hover 抬升。

### 高危信号

| 信号 | 检测标准 | 严重度 |
|------|----------|--------|
| 阴影层级混乱 | 唯一阴影值 > 4 种 | 高 |
| 阴影层级过深 | 最大阴影模糊半径 > 40px（非浮层） | 中 |
| 圆角值混乱 | 唯一 `border-radius` 值 > 4 种 | 中 |
| 圆角通用化 | 大圆角（≥16px）用于控件（按钮/输入框） | 中 |
| 装饰性光晕 | 使用 `text-shadow` glow / `filter: drop-shadow` 做装饰 | 中 |
| 全员 hover 抬升 | 所有卡片都有 `hover:shadow-lg` 类效果 | 中 |
| 装饰交付为零留白 | 区块间无呼吸区，内容贴边 | 高 |

### 阈值备忘

- **阴影尺度 ≤ 3 档**（raised / popup / card），且每档只对应一类语义
- **圆角 ≤ 3 档**：控件档 / 表面档 / 胶囊档
- **「每屏动画元素 ≤1–2 个」**——超过就是过载
- 留白不是「剩余空间」，是**主动分配的资源**

## D4 · 排版扁平

### 在衡量什么

层次**对比度**够不够狠。字号只差一点点 = 没有层次。

AI 生成倾向：全站 16px/24px，字重只用 400 和 700，标题与正文比 < 2:1，缺少字距处理。

### 高危信号

| 信号 | 检测标准 | 严重度 |
|------|----------|--------|
| 字号尺度稀疏且均匀 | 唯一字号数 < 4，且相邻档差 < 1.3× | 高 |
| 标题/正文比不足 | 最大标题 ÷ 正文字号 < 2.0 | 高 |
| 字重单一 | 唯一字重数 < 3 | 中 |
| 字重极端 | 使用 100–300 或 700+ 做界面 chrome 文字 | 中 |
| 行高均一 | 所有文本行高完全相同，无紧凑/宽松区分 | 中 |
| 缺字距处理 | 大字号标题未收紧字距（`letter-spacing` 未设） | 低 |
| 数字未等宽 | 数据列/价格/计时未用 `font-variant-numeric: tabular-nums` | 中 |

### 阈值备忘

- 至少 **5 档**字号，且最大/最小比 **≥ 3.5×**
- 标题与正文对比 **≥ 2.0×**；强对比可达 **3–5×**
- 字重建议 **3 档**：400（正文）/ 500（标签）/ 600（标题）
  - ⚠️ 企业级产品可只用 **400 + 600**（Ant Design 口径），但**必须有字距与色彩补偿**

## D5 · 结构同构

### 在衡量什么

不同页面的**骨架是否复制粘贴**。结构同构 = 没读内容 = 模板腔。

AI 生成倾向：每个页面都是「页头 + 副标题 + 三等分卡片 + 底栏」；列表页与详情页骨架一样。

### 高危信号

| 信号 | 检测标准 | 严重度 |
|------|----------|--------|
| 骨架重复 | 连续 ≥2 个区块使用完全相同的网格结构 | 高 |
| 默认三段式 | 全站存在 3 处以上「标题+副标题+3 卡片」 | 高 |
| 空状态缺失 | 无空数据态、无加载骨架 | 高 |
| 详情页与列表页同构 | 两者布局差异 < 20% | 中 |
| 信息层级均质 | 所有卡片视觉权重相同，无主卡/次卡 | 中 |
| 区块数失控 | 单屏并列模块 > 9 个（无重点） | 中 |

### 阈值备忘

- 相邻区块结构**必须至少有一处不同**（列数 / 跨列 / 方向 / 密度）
- 一屏并列模块控制在 **5–9 个**，且必须有一个视觉上明显主卡
- 结构由内容决定：**先数列出内容，再画骨架，不要反过来**

## D6 · 语义空洞

### 在衡量什么

文案**说了等于没说的话**。这是 AI 味最重的部分，也最快被用户察觉。

AI 生成倾向：`Empower your workflow`、`Seamlessly integrate`、`Your all-in-one solution`、emoji 当图标、通用积极收尾。

### 高危信号

| 信号 | 检测标准 | 严重度 |
|------|----------|--------|
| emoji 当图标 | 出现 ≥1 个 emoji 承担图标职责 | 高 |
| 空洞正向词 | 命中空洞词表（见 `copy-tells.md`） | 高 |
| 通用积极收尾 | 结尾为「开启旅程」「解锁可能」类表述 | 高 |
| 不含具体值 | 无数字、无具体名词、无场景 | 高 |
| 三词排比 | 「快速、安全、可靠」类无信息量并列 | 中 |
| 自称全景 | 「一站式」「全方位」「all-in-one」 | 中 |

### 阈值备忘

- **每条标题里至少有一个具体名词或数字。**
- 判据：**把句子里的产品名换成竞品名，还成立吗？** 成立 = 空洞。

## 评分标准

自检脚本按六维给出 0–100 的 **AI 味总分**（越高越像 AI）。

| 分档 | 区间 | 含义 | 处理 |
|------|------|------|------|
| **A** | 0–20 | 有明确立场，可交付 | 走交付清单 |
| **B** | 21–40 | 基本成型，局部惰性 | 按清单改造 1 轮 |
| **C** | 41–60 | 明显模板感 | 改造 2 轮，并回查 G1 主张 |
| **D** | 61–80 | 通用模板 | **回退 G1/G2 重做立场与风格** |
| **E** | 81–100 | 默认主题直出 | 重做 |

> **分数只用于定位，不用于交付。** 报告的**逐项清单**才是行动依据。
> 分数低但有 1 条「高危」未解决，仍然不可交付。

## 无脚本时的手动 CT 扫描

| 诊断项 | 检测标准 | 高危信号 |
|--------|----------|----------|
| 居中密度 | 居中类声明 ÷ 布局类声明 | > 45% |
| 等分栅格 | 等宽列出现次数 | > 2 次且无理由 |
| 唯一色相 | 不含灰的色相数 | > 6 |
| 硬编码色值 | 组件内裸 hex 数 | > 0 |
| 唯一阴影值 | `box-shadow` 去重后数量 | > 4 |
| 唯一圆角值 | `border-radius` 去重后数量 | > 4 |
| 字号档数 | 唯一 `font-size` 数 | < 4 |
| 标题/正文比 | 最大字号 ÷ 正文字号 | < 2.0 |
| 字重档数 | 唯一 `font-weight` 数 | < 3 |
| 骨架重复 | 连续同构区块数 | ≥ 2 |
| emoji 图标 | emoji 承担图标职责数 | ≥ 1 |
| 空洞词 | 命中 `copy-tells.md` 词表 | 任意命中即需复核 |
| 状态覆盖 | 是否含 hover/focus/disabled/loading/empty/error | 缺任一即高危 |
