## 十、填写示例（片段）

| 项 | 内容 |
|----|------|
| 场景 | 企业监控界面 |
| **主风格** | 05 Data-Dense Dashboard |
| **辅风格** | 无 |
| 旋钮 | V3 / M2 / D9 |

**被否决的候选：**

| 被否决风格 | 否决理由 |
|-----------|----------|
| 06 Dark Mode (OLED) | 白天班次也在用，全暗色不利于日间阅读；改为中性深灰而非纯黑 |
| 08 HUD Sci-Fi FUI | 发光与环形仪表会与告警争夺注意力——本项目的唯一重点必须是告警本身 |
| 03 Bento Box Grid | 便当格靠卡片尺寸制造节奏，但监控界面的空间位置必须稳定（值班员靠肌肉记忆扫视） |

**为什么不用最稳妥的 21 Accessible & Ethical？**
> 它的调性偏「公共基础设施」，而本项目是内部工具，需要在夜班场景下降低屏幕溢光——深色 + 高密度是刚需，而 21 的标准形态是浅色 + 宽松。

**AI 味陷阱自查：**

| 陷阱 | 已规避 | 具体做法 |
|------|:------:|----------|
| 「太密了改成卡片留白」 | ✅ | 明确写入误杀预声明，密度是特征 |
| 无层次导致糊 | ✅ | 灰度分 4 档，主/次/三级文字 + 禁用态层级分明 |
| 用彩色 UI 抢数据的色 | ✅ | UI 全中性，色彩预算完全留给状态编码 |
